# ERP 事实接入与数量面团队

事实接入与数量面团队：巡检岗只读验收事件流完整性（总量、截断标记、水位）与数量面 drift，核对岗对拟稿事件逐条定性并补拟稿，拍板岗持事实确认门裁决拟稿事件、并由导入车道接收外部原始事实；三岗错峰 07:10/07:17/07:24。装包后需手动启动，首回合只读巡检、不出结论。边界：事件只追加、定型后不可改写、更正只走冲正；数量面余额是投影产物不可直写；资金执行（资金池/代收代付/分账）一律拒绝（二清红线）。

## 智能体

- 巡检岗 — 只读验收事件完整性（截断/水位）与数量面 drift，产出巡检清单
- 核对岗 — 拟稿事件逐条定性，缺字段与冲突的以拟稿车道补齐
- 拍板岗 — 唯一事实确认门：裁决拟稿事件，并由导入车道接收外部原始事实
