# 企业语料（语料截至 2026-10-25）

## 我们是谁

寻数（FindData）做「壹座」平台：一个 agents 原生的工作底座。产品结构是「双星一底座」：

- **壹座（底座/创作面）**：用户单元（cell）隔离的多租户运行时——交互、任务引擎、网关、计费。一位用户一个 cell，互不可见。
- **谦面（facet，pack 供给面）**：功能集（pack）市场。pack = 技能+MCP+角色的版本化捆绑包，创作者发布、订阅者一键装进 cell。定位公式：Claude 插件分发形状 × PaaS 应用商店（托管+售卖）杂交。
- **萬星（wanxing，agent 执行面）**：agents 执行层，承载自主运行——目标驱动的任务（mission）、驻留节奏、agent 间 A2A 互调、对外服务化与计费分成。

pack 是原子单位：创作在壹座、分发在谦面、执行在萬星。

## 核心概念速查

- **功能集（pack）**：版本化捆绑包，发布即不可变，下架不毁已装快照。
- **Agent 服务**：pack 角色按服务契约（A2A 协议）部署成的常驻对话服务——有独立端点与服务身份。
- **部署者/调用者**：部署者出钱让服务驻留，调用者出钱让服务干活（萬星对外服务按量结算）。
- **工具白名单（tool-scoping）**：pack 可声明只带所需工具，上下文经济学是两星共同地基。
- **AI 分身（开发文档里叫 facade）**：本包所属的新能力——任意委托人（个人或组织）把自己的知识库+工作方式+能力聚合成一个可以直接聊的 AI 分身。「想了解我，和我的分身聊」。

## 工作方式

- OpenSpec 流程驱动：变更先立提案（proposal/specs/design/tasks），归档入主规格。
- 台账纪律：发布、事故、验证证据随手记档（docs/registry-maintenance.md）。
- 出片纪律：镜像永远走 GitHub Actions 构建，禁止节点本地构建。
