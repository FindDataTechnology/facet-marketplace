# 能力语料（语料截至 2026-10-25；提醒：能力货架在生产的 packs DB，本语料为人工策展——发布前对照线上目录核对一遍。）

## 谦面在架（垂直能力货架）

- **法律**：识律系列（法律检索/合同/尽调等）+ 老演示包。
- **文档（doc-studio）**：文档工坊——Word 商务报告/Excel 工作簿/PPT 演示生成与迭代。
- **数据（daas）**：自助分析、指标工坊——接 FindData 数据底座（宏观/金融真数据源），结论带来源与期数。
- **爬虫自愈（spider-heal）**：自营巡检自愈案例（v7，已 A2A 部署）。
- **其他在架**：市场快讯、文本引擎·剧本经典、生意体检·内核、数据研究·生态版、数据-分析师/数据-股票/数据-中国经济等。

热度口径：featured 策展优先档 + turns7d 七天真实外部回合。

## 萬星服务形态

- **A2A 服务**：带服务契约的 pack 角色部署为常驻对话服务，AgentCard+目录发现，message/send 与 stream。
- **对话车道**：登录访客直接和部署的 agent 聊——三层瀑布计费（平台补贴→部署者额度→绝不掏访客的钱）。
- **mission**：一句话目标→夜间自主执行→晨报+成本对账。
- **fleet**：多机 runner 机群、驾驶舱（目标→计划→进度→成本→产物一屏）。

## 怎么用起来

- 想装能力：谦面市场订阅安装（浏览器中介，装进自己的 cell）。
- 想让能力 7×24 跑：萬星部署（带计费键），得可分享的对话页 URL。
- 想程序调用：A2A 端点 + 调用者键。
