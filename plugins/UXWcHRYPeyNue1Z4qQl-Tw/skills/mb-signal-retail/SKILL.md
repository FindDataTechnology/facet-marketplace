# 零售信号包

**本技能是内核套件「生意体检」（`mb-business-checkup`）的行业信号姊妹件。** 内核在阶段 3 调用本技能；本技能**只做零售行业的环境信号读取与解读**，不做问诊、不做盈亏平衡/毛利/现金流计算，也**不修改内核工作流**。

**叠装契约**：内核 + 本包 = 完整零售版体检。只装内核不装本包时，内核走"未安装行业信号包"降级分支并如实标注——这是预期行为。

**适用**：便利店、花店、生鲜店、社区小店、兼营电商/社区团购的小店。

---

## §0 与内核的协作契约（本包声明）

| 信号 id | 信号名 | 数据来源单元 | 频率 | 是否代理 |
|---|---|---|---|---|
| `retail.wholesale_price` | 批发价参考 | flower-auction（昆明花拍） | 日 | 否（真实批发价，限花卉/生鲜） |

## §1 批发价参考（`retail.wholesale_price`）

### 读什么

昆明国际花卉拍卖中心（`flower-auction` 单元，kifa.net）日度拍卖价与行情分析。

### 适用范围（硬边界）

**仅对花卉与生鲜类有效。** 这是真实的批发端成交价，对花店/生鲜店是**进货成本的直接参考**。

**禁止泛化**：MUST NOT 把它说成"所有零售商品的批发价"。卖日用品、烟酒、零食的店，本信号**不适用**——直接说明该信号对本品类不适用，不要拿花卉价格套其他品类。

### 怎么读

1. 取近期日度拍卖价与行情分析
2. 看方向与波动幅度（花价波动本身较大，看周均值比看单日更稳）
3. 对应到用户进货品类（玫瑰/百合/配花等）

### 异动意味着什么

上行 → 进货成本压力，需考虑提前采购或调整定价/品类结构。下行 → 进货窗口。

### 局限

拍卖中心价是**产地/批发端**价格，本店进货还要经过中间环节（运费、损耗、二级批发加价），**不等于本店到手进价**。

### 取不到时

如实标注「批发价信号未连接」，本信号段不输出，其余信号继续。**不得**用模型记忆的价格填充。

## §2 城市基本面（`retail.city_fundamentals`）

### 读什么

中国城市面板（`mcp__fd-find-data-business-mcp__city_search_variables` → `mcp__fd-find-data-business-mcp__city_read`，209 变量 × 297 城 × 2000–2024）；年鉴口径（`yearbook_search_indicators` → `yearbook_read`）。

### 怎么读

按开店决策需要选变量（**先搜后读，不猜变量名**）：

| 决策问题 | 变量方向（用搜索工具定位实际指标） |
|---|---|
| 这个片区消费力如何 | 居民收入、消费支出类 |
| 人多不多 | 常住人口、人口密度类 |
| 就业稳不稳 | 就业、城镇单位人员类 |

### 异动意味着什么

收入上行 + 人口流入 → 社区消费力趋强，适合做品质/客单升级。收入停滞 + 人口流出 → 需更重性价比，控制库存与租金。

### 局限

城市面板是**年度、市域口径**，不是社区/街道口径；一个城市内部的片区差异很大。它回答"这座城市的大盘怎样"，**不回答"你这个小区门口的人怎样"**。

### 取不到时

如实标注「城市基本面信号未连接」，本信号段不输出。

---

## §3 同业密度（`retail.competition_density`）

### 读什么

工商登记（`ia35`）：`mcp__fd-find-data-business-mcp__ia35_reg_counts_read`（新增注册数，支持 `province` + `city` + `county`，行业下钻 `industry_level` = 门类/大类/中类/小类）与 `mcp__fd-find-data-business-mcp__ia35_company_search`（企业档案，`company_type="个体工商户"` 可筛个体户，个体户约占库内抽样 48.5%）。

零售对应行业示例：**零售业（门类 F）** 下可下钻到具体中类/小类（用搜索或逐级试探定位实际代码与名称）。

### 参数陷阱（必读）

`ia35_reg_counts_read` 的 `city` / `county` 过滤**必须同时提供 `province`**，否则返回 `invalid_params`（无省份锚点会退化为全表扫描并超时）。调 county 前先确认用户给的区县名能对应库内口径；对不上就回问，不要猜。

### 两条硬标注（缺一即不合格输出）

1. **批次与时效**：输出必须标注**批次年份**（取自工具响应字段 `latest_year_available` / `batch_year` / `snapshot_year`，**不得凭记忆填写**），并写明「**历史格局，非实时**」。它回答"这条街历史上是什么竞争强度"，**不回答**"最近三个月新开了几家"。
2. **无注销/吊销口径**：数据源只有**新增注册**口径。用户问"这条街关了多少家""这行倒闭率多少"——**必须明示做不了**，并给出可得替代：**存量快照的状态分布**（走 `ia35_company_search` 的 `status` 字段看在营/存续/吊销未注销/注销等状态的占比）。**禁止编造关店数量、禁止估算退出率、禁止用新增注册下降反推关店。**

### 局限

登记层面的密度 ≠ 实际竞争强度。存活率、经营质量、客群重叠度都在数据之外；且滞后约 3 年，只宜作**长期格局判断**。

## §4 电商景气（`retail.ecommerce_climate`）

### 读什么

国家邮政局快递月报（`spb-express` 单元，36 期连续，含业务量/收入/CR8 集中度）。

### 怎么读

1. 取快递业务量与收入序列，看同比/环比方向
2. 看 CR8（前 8 家集中度）变化——集中度上升说明头部平台/快递更强势，小店的议价空间变化
3. 结合用户是否兼营电商/社区团购判断相关性

### 异动意味着什么

快递量上行 → 线上消费大盘活跃，兼营线上渠道的相对有利。下行 → 线上大盘降温，社区线下渠道的相对价值回升。

### 局限

**这是全国大盘，不是本店的电商单量。** 全国快递量涨不代表你的店能分到；也不反映平台规则、流量成本、佣金变化（这些不在数据源内）。

### 取不到时

如实标注「电商景气信号未连接」，本信号段不输出。

---

## §5 "关店/退出"类问题的诚实应答（本包强制段）

用户问以下任一：**"这条街关了多少家""这行倒闭率多少""最近有多少店不干了"**

**固定应答口径**：

```
【关于关店数据】这个数做不了。
  原因：工商登记数据源只有"新增注册"口径，没有注销、吊销、关店的流量口径——
       也就是说，只能看到新开出来的，看不到关掉的。
  可以给你的是：这批登记底册里，各状态店的占比（在营/存续/吊销未注销/注销等）。
  注意：这是 <批次年份> 年的历史底册，反映的是当时的存量格局，不是最近的关店情况。
```

**硬失败项**：给出任何关店数量、退出率、倒闭率；用新增注册数下降反推"关了 X 家"；说"大约"给一个估算。

## §6 汇总输出格式（交给内核阶段 3）

每个信号四行，缺依据不许写：

```
【信号】批发价参考（真实批发端价格，限花卉/生鲜）
  读数：<近期拍卖价方向与幅度，附来源与口径时间>
  含义：<进货成本提示，给方向不给编造幅度>
  局限：产地/批发端价 ≠ 本店到手进价（运费/损耗/二级加价）

【信号】同业密度（存量格局，非实时）
  读数：<区县+行业小类的历史新增注册序列，附批次年份>
  含义：<长期竞争强度判断>
  局限：批次 <年份> 历史格局；无注销口径，看不到关店；登记密度 ≠ 实际竞争
```

**汇总顺序**：先进货价（直接影响钱），再城市基本面（影响选址与定位），再同业密度（影响长期判断），最后电商景气（影响渠道策略）。

**信号源不可用**：该信号段写「<信号名>未连接」，其余照常，**分析不中断**。

## §7 术语对照（面向小老板）

| 术语 | 日常语言解释 |
|---|---|
| 批发端价 | 产地或大批发市场的价，你进货还要加上运输和中间环节 |
| 存量状态分布 | 现在册子上这些店各是什么状态（还在开/已注销等）的占比 |
| 批次快照 | 某一年的登记底册，不是今天实时的情况 |
| CR8 | 前 8 家大公司占的市场份额，越高说明越集中在头部 |
| 代理信号 | 不是直接量你的店，而是量大盘环境，只能当参考 |

## hard_constraints

1. **每个信号 MUST 标注口径与局限**；代理类信号 MUST 写明"它反映什么、不等于什么"，禁止表述成对本店的直接测量。
2. **批发价信号 MUST 限定在花卉/生鲜范围**，MUST NOT 泛化为所有零售品类。
3. **信号源不可用即降级**：MUST 明示「未连接该数据源」，分析在其余信号上继续；**禁止**用模型记忆的价格、密度、景气数值填充。
4. **数值 MUST 来自工具实际返回**，附来源与口径时间；禁止编造任何价格、注册数、快递量。
5. **工商类信号 MUST 带批次年份与「历史格局，非实时」标注**；批次年份 MUST 取自工具响应字段，禁止凭记忆填写。
6. **无注销口径 MUST 明示**：涉及"关了多少家/倒闭率/退出量"的提问，MUST 按 §5 固定口径明示做不了并给存量状态分布替代；**禁止编造关店数量、禁止估算退出率、禁止用新增注册下降反推关店**。
7. **不重复内核工作**：本技能 MUST NOT 包含问诊建档、盈亏平衡、毛利结构、现金流账期计算；也 MUST NOT 修改内核工作流。
8. **术语可懂**：专业术语首次出现 MUST 附日常语言解释。
9. **不承诺实时性**：MUST NOT 将批次快照数据呈现为实时登记状态。

**硬失败项**：把批发价泛化到非花卉生鲜品类；信号未连接却给出数值；工商类输出缺批次年份或"非实时"标注；被问关店量时给出任何数量或比率。

## 免责声明

本技能输出的环境信号为大盘/区域指标或历史批次快照，反映的是区域环境与历史格局而非本店实际经营数据，仅供经营参考，不构成投资或经营决策建议。工商登记数据为历史批次快照，不反映实时状态，亦不含注销/吊销口径。最终经营决策由经营者本人作出。
