# 生意体检 · 内核套件

面向中国传统微型企业与个体户的经营体检内核：四段式工作流（问诊建档 → 单店算账 → 行业信号对照 → 行动清单）为入口技能，配套盈亏平衡、毛利结构、现金流账期三个计算器。所有金额与比率一律经计算器产出并附计算公式 + 输入基数 + 来源（来源名/地区/年份/口径时间），外部统计基数取不到时该项中止并明示「基数数据源未连接/未定码」，禁止用模型记忆的行业数字填充。未安装行业信号包时如实标注「未安装行业信号包」且不中断分析。单店生意档案可建立在 DAAS 实体模型上（一家店=一个实体，指标持久化 + 告警规则）。内核按小老板能听懂的标准书写，专业术语附日常解释；机构与政务渠道共用同一内核，仅外壳与推送方式不同。

## 技能

- mb-business-checkup — 生意体检（谦面·面向个体户与微型企业的内核入口技能）。当小老板描述自己的店（餐馆/便利店/花店/网店）、或代账、银行普惠客户经理、园区运营要为商户做经营诊断时使用。四段式：问诊建档 → 单店算账（点名盈亏平衡/毛利结构/现金流账期三计算器）→ 行业信号对照 → 行动清单。数值只由计算器产出并附公式与来源；未装行业信号包时如实标注，不中断分析。
- mb-breakeven-calculator — 盈亏平衡计算器（谦面·面向个体户与微型企业的三个原子计算器之一）。当小老板或代账要算「一个月卖到多少才不亏」「每天要来多少客人/多少单才保本」「离保本线还有多远」「按现在的流水多少天能 cover 固定成本」时使用。产出月盈亏平衡流水、保本客流/单量、安全边际、保本天数，每个数字附计算公式、输入基数与来源标注。只做计算，不做问诊。
- mb-margin-structure-calculator — 毛利结构计算器（谦面·面向个体户与微型企业的三个原子计算器之一）。当小老板或代账要算「毛利有多少」「哪块成本占得最重」「房租人工占流水几成」「涨价能多赚多少」时使用。产出固定/变动成本拆分、各项成本占流水比、毛利率与边际贡献率、成本结构诊断。每个数字附计算公式、输入基数与来源标注；外部基数取不到即中止该项，禁止用模型记忆的行业数字填充。只做计算，不做问诊。
- mb-cashflow-terms-calculator — 现金流与账期计算器（谦面·面向个体户与微型企业的三个原子计算器之一）。当小老板或代账要算「手里要留多少周转金」「什么时候会缺钱」「供应商账期和客户账期对不上怎么办」「旺季备货钱够不够」时使用。产出最少周转金、现金流缺口时段与金额、账期占款、季节性缓冲建议。每个数字附计算公式、输入基数与来源标注；外部基数取不到即中止该项，禁止用模型记忆的行业数字填充。只做计算，不做问诊。
