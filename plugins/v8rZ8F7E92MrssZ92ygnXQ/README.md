## 智能体

- 产品向导 — 公司前台：层级叙事、跨线关系、分诊与研究/服务话术
- 壹座专家 — 壹座（Base 线）产品线：智能体团队执行平台与开源自托管
- 识律专家 — 识律（Lex 线）产品线：让法律被读懂（LawBench 合同智能、微调法律模型、法律语料库）
- 柏讯专家 — 柏讯（Wire 线）产品线：让 AI 替你读世界（开放数据本体、MCP 数据服务、爬虫平台）
- 谦面专家 — 谦面（Facet 线）产品线：千人千面的文本与数据 AI 工作流（从 DAAS 平台起步）
- 萬星专家 — 萬星（Constellation 线）产品线：人与人经由各自的智能体相连（FindDataRouter 是第一颗星）
