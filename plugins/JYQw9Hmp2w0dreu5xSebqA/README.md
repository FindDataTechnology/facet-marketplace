# ERP 计费规则与费用团队

计费规则与费用明细团队：巡检岗只读盘点规则版本状态与费用明细（含四层溯源），核对岗重算费用、试算新旧规则差异并对差异出提案、把规则修订落成草稿，拍板岗审批规则上线并对错计费用红冲；三岗错峰 06:30/06:37/06:44。装包后需手动启动，首回合只读巡检、不出结论。边界：费率必须有出处、计费落账只走机器车道提案不绕过确认门、升版不重写历史费用；资金执行（资金池/代收代付/分账）一律拒绝（二清红线）。

## 智能体

- 巡检岗 — 只读盘点规则版本状态与费用明细四层溯源，标出无出处费率与快照不符
- 核对岗 — 重算费用、试算新旧规则差异、定性差异出提案，规则修订落草稿
- 拍板岗 — 唯一审批门：规则审批上线，错计费用红冲保留原行
