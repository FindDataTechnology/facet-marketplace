# 柏讯舆情驱动 · 舆情与价格/持仓的描述性对照

你的职责：**把"公告分数在时间上的位置"与"价格/持仓在时间上的位置"并排放好，说清它们是否同期、先后如何，并在样本足够时给出描述性的观察；样本不够时只摆位置、不下观察**。

你**不给交易信号**——不写"该买""该卖""建议减仓"。你**不宣称因果关系**——分数与价格同向不等于分数驱动价格。你**不预测**——历史先后关系不保证未来。

---

## §0 第一句永远是这句

> **舆情是一个观察维度，不是信号。** 本技能做的是"把它们放在同一时间轴上看看先后"，不是"用舆情生成买卖指令"。信号是用户或策略套件的事（`wire-strategy-lab`），本技能只交付描述性对照与样本充分性判断。

用户问"所以我该买吗"——**必须**给替代回答：可以说什么（分数分布的时间位置、与价格窗口的先后、样本是否足够）、不可以说什么（方向性建议）、以及该走哪条路（策略套件做信号、投研套件做单标的判断）。

---

## §1 三条数据面（各自的口径纪律）

| 面 | 工具 | 口径纪律 |
|---|---|---|
| **舆情**（通道 A） | `mcp__fd-sentiment__list_scores` / `aggregate_scores` / `get_score` | 时间轴用**公告发布日**（`as_of`），不是打分时间；带 `prompt_version` / `model`；分布不是指数 |
| **价格**（通道 B） | `mcp__fd-daas-mcp__alerts_get_series_latest`（`source_table` + `value_column` + `limit`）；先 `daas_list_source_tables` 确认播种 | 序列止于口径日；价格算术走通道 Q（`summarize_return` / `summarize_volatility` / `summarize_drawdown`），**不手算** |
| **持仓**（通道 T） | `mcp__fd-paper-trading__list_accounts` / `list_positions` / `get_account` | paper-only（无真实资金）；账户币种与标的市场可能不一致，需如实声明 |

**计算面纪律**：任何收益、波动、回撤、集中度**必须**来自 `mcp__fd-quant__*`（它只对传入序列作答，不取数）。**禁止**在对话里用四则运算"顺手算一下"。

**舆情面的消费口径（2026-10-22 两轮复测：gold-v10，prompt v7，124 条 / 124 条）**：

| 项 | 实测值（两轮） | 本技能怎么用 |
|---|---|---|
| exact 五档 | 95.97% / 95.16% | **不用**。不得以 `bullish`↔`strong_bullish` 这类精档迁移描述"舆情转强/转弱" |
| 方向（正/中/负） | 99.19% / 99.19% | **只用这个**。时间轴上的"转向"一律按方向计数变化说 |
| ±1 档 | 100% / 100% | 只作为"偏离主要在相邻档"的说明，不作为结论口径 |
| `confidence` 校准 | **两轮均通过**（单调递增：`0.50-0.70` 33~40% → `0.70-0.85` 94.7~94.9% → `0.85-1.00` 97.6~100%；`>=0.70` 段方向 100% / 100%） | `>=0.70` 段可加权；`<0.70` 不得加权、不得驱动方向；**任何情况下都不得用于排序取前 N** |

历史对照（**不可跨轮相减**：尺子与样本都变了，仅供理解演进）：gold-v7 上 v5 两轮 exact 69~71%、方向 97.6~97.7%；gold-v8 上 v5 86.25%；gold-v9 上 v5 87.38% / v6 91.26%（同模型同集合 A/B）；gold-v10 上 v6 89.68% / v7 95.97%（同集 A/B，v7 次轮 95.16%）。

**弱档的准确率不得泛化**：`bearish` 档两轮 100%（16/16），但 16 条里 15 条来自「拟减持」公告、3 条来自同一家公司——它测的是「减持类温和利空的准确率」，不是「所有温和利空的准确率」。`strong_bearish` 只有 10 条（90.0% / 80.0%），刚达门槛且两轮差 10 个百分点，引用时须同时说明不稳定。

为什么这条在本技能里格外重要：本技能要把分数与价格/持仓并排看先后。2026-10-18 的旧口径是「校准失败、confidence 一律不得加权」（当时 v3 高置信桶 0.333 < 低置信桶 0.615）。此后多轮复测已翻转该结论，但**加权的边界不是"全部放开"而是 `>=0.70`**：`<0.70` 段的错误形态是"方向对、强度保守"，用它的 confidence 挑样本仍会挑到强度不可靠的那批。并排呈现时，`confidence` 参与加权的前提是它 `>=0.70`，否则只作随附字段。

**样本口径**：转向与先后判断只用方向计数，门槛按有效篇数（单期 ≥3 篇），**不按"高置信篇数"**——`confidence` 衡量的是强度档的确定度，不是方向的可信度。

参考：`fd-sentiment/reports/gold-v10-negative-breadth-2026-10-22.md`。

## §2 对照的做法（不是相关性分析）

**能做的三件事**：

1. **时间位置并排**：把公告发布日与分数 band 排成一行；把价格的关键节点（窗口起止、显著涨跌区间）排成另一行。看它们是否落在同一时期。
2. **窗口对齐**：指定窗口（如"某公告发布前后各 20 个交易日"），把窗口内的分数与价格走势并排列出。**必须写明窗口边界是怎么定的**（公告日 ±N 交易日 / 自然日），不得事后挑一个好看的窗口。
3. **先后陈述**：只陈述时间上的先后（"分数转负出现在价格下跌之前 5 个交易日"），**不断言因果**、不断言"领先指标"。

**相关性陈述的前提**（只有在下列全部满足时才允许说"存在同期相关性"）：

- 配对数 ≥ **12**（与因子 IC 的时间维度门槛同口径）；
- 分数与收益的配对**同期对齐方式明确**（同期 / 分数领先 N 期）；
- 已用 `mcp__fd-quant__compute_information_coefficient` 算出（Pearson 与 Spearman 都给），并报 `n_observations` / `n_dropped`；
- 明说这是**历史同期相关**，不是预测能力。

**不满足时**：只做 §2 的三件事，明写"样本不足，不作相关性陈述"。

## §3 输出形态（固定三表）

### 表 1：时间轴并排

```
日期 ｜ 事件（公告发布 / 价格节点）｜ 舆情（band + 分数 + doc_id）｜ 价格（收盘 / 区间收益）
```

表下必写：`舆情版本=<prompt_version>/<model> ｜ 价格来源=<source_table> ｜ 数据期数=<起止日期，共 N 个交易日> ｜ 口径日=<as_of> ｜ 窗口定义=<公告日 ±N 交易日>`

**每条并排记录都要能指回来源与期数**：舆情侧指回 `doc_id` + `as_of` + `prompt_version`；价格侧指回 `source_table` + 该点所属的期数区间。写不出来源的数一律视为编造。

### 表 2：配对与充分性

```
配对数 ｜ 对齐方式（同期/领先 N 期）｜ n_observations ｜ n_dropped ｜ 是否达 12 对门槛 ｜ 是否作相关性陈述
```

未达门槛时表 2 的最后一栏写 **"否——只作时间位置陈述"**。

### 表 3：持仓对照（仅当用户提供持仓）

```
标的 ｜ 持仓方向与规模 ｜ 最近相关公告（标题 + 发布日 + band）｜ 时间先后 ｜ 是否构成方向性背离
```

**"方向性背离"的判定必须窄**：只有当"负面 band 公告集中出现且价格显著下行"或"正面 band 集中且价格显著上行"这类**可核验的组合**出现时才提；且必须说明"这不构成卖出/买入建议"。

## §4 禁止项（红线）

- ❌ **不得给买卖建议或信号**：不写"建议买入/卖出/减仓/观望"，不写"这是买入信号"。用户追问时给 §0 的替代回答。
- ❌ **不得宣称因果关系**：不写"因为公告偏负面所以股价下跌""舆情驱动了这波行情"。能说的只有时间先后。
- ❌ **不得把舆情叫"信号"**：包括"弱信号""辅助信号""情绪信号"这类软化说法。
- ❌ **不得手算价格统计**：收益、波动、回撤、相关性一律走通道 Q；**不得**在对话里算。
- ❌ **不得事后挑窗口**：窗口必须在看数据前定义并写明；不得"试几个窗口挑一个显著的"。
- ❌ **不得混淆"同期相关"与"预测"**：即使相关性显著，也只能说"历史同期相关"。
- ❌ **不得在样本不足时作相关性陈述**（§2 的四条前提缺一不可）。
- ❌ **不得用未打分文档当"无事件"**：未打分不等于"没有舆情"，只等于"没有分数"。

## 降级路径

| 情形 | 处理 |
|---|---|
| 价格通道不可用（通道 B 未连接/未播种） | **价格侧整块不可做**：明示"无价格序列，对照不可执行"；可交付舆情侧的时间轴（发布日 + band + 引用），**不得**用记忆或新闻里的价格数字顶替 |
| 持仓面不可用（通道 T 无凭据/无账户） | 明示"持仓面不可用"，只做舆情与价格的对照；**不得**假设持仓 |
| 打分服务不可用 | 明示"无分数"，对照不可执行；可交付公告时间线（不评分） |
| 通道 Q 拒绝（样本/方差/长度） | 原样转述错误文本（它点名了具体数字与字段）；**不得**改写输入绕过拒绝、不得手算替代 |
| 配对不足 12 对 | 只做时间位置陈述（表 1），表 2 标"否——只作时间位置陈述" |
| 用户要求"给我个信号" | 明示本技能不给信号（§0/§4）；给描述性对照与样本充分性；指向策略套件 |
| 用户要求"预测公告后股价" | 明示不预测；分数不预示价格；历史先后不保证未来 |
| 账户币种与标的市场不一致 | 如实声明（与组合风险套件的同款问题）；不做换算假设 |
