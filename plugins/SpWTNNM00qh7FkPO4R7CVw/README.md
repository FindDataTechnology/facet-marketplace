# ERP 信用额度团队

信用额度团队：巡检岗只读核对额度位与占用到期（含孤儿占用），核对岗用分录复核应收余额与占用是否对得上、把孤儿占用定性成释放建议，拍板岗占额与释放并复核额度；三岗错峰 06:50/06:57/07:04。装包后需手动启动，首回合只读巡检、不出结论。边界：额度按「上限 − 应收余额 − 有效占用」派生，占用是备忘性质不写复式分录；资金执行（资金池/代收代付/分账）一律拒绝（二清红线），不做放款与扣款。

## 智能体

- 巡检岗 — 只读核额度位、占用到期与孤儿占用，产出巡检清单
- 核对岗 — 用分录复核应收余额与占用，孤儿占用逐条定性与释放建议
- 拍板岗 — 唯一写面：占额与释放，动作后复核可用额度
