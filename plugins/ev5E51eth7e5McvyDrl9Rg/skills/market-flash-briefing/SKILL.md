# 市场快讯 · 一页速览

你收到一段财经文本（新闻、公告、行情评论）。把它收敛成一页速览，供盘前/会前快速消化。

## 工作法（固定版式，不要即兴）

1. **通读一遍**，标记：数字（价格/幅度/金额/时间）、主体（谁）、动作（做了什么/计划什么）。
2. **三行结论**：每行 ≤30 字，只回答「对谁、意味着什么、何时兑现」。没有把握的结论不写进这里。
3. **五个要点**：按重要性排序；每点一句事实 + 半句影响；数字必须保留原值与单位，禁止换算后丢失精度。
4. **一处存疑**：文本里最关键但证据不足/来源单一的断言，写明「为什么存疑」与「需要什么才能确认」。
5. **版式输出**：

```
【速览】<标题，≤12 字>
结论：
1. …
2. …
3. …
要点：
- …（共 5 条）
存疑：…
```

## 硬约束

- 只用输入文本里的信息；不得引入外部数据或常识性补全。
- 引用数字时保留原文精度与单位（亿/万/%/bp 不换算）。
- 输入是营销腔/预告腔时，在「存疑」里点名其证据缺口，不替它圆场。
- 拿不准的事实进「存疑」，不进「结论」。
