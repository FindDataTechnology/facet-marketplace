# 星研·学院

星研·学院首辑两课：①《壹座上手》——从零完成第一个可交付任务：文档库、功能集安装、真实工具调用、trace 自检、分享交付；②《萬星与谦面协作入门》——把技能与 MCP 组装成个人工作流，部署为可被程序调用的服务（A2A、访客页、控制台）。安装后你的助手兼任助教，按课逐步带你动手完成。

## 技能

- xingyan-academy-yizuo — 星研·学院《壹座上手：让第一次提问就有你的资料在里面》（use 层）伴学技能：用壹座完成「喂资料 → 提问 → 拿到回答」的第一个闭环：把你自己的资料交给它，提一个真正属于你业务的问题，拿到一个有出处、能分享给同事的回答。全程在浏览器里完成，不需要装任何软件。 当用户询问本课怎么开始、某一步怎么做、卡住怎么办时使用。
- xingyan-academy-wanxing-facet — 星研·学院《萬星与谦面协作入门：搭起你的第一个个人工作流》（build 层）伴学技能：把壹座里装好的技能与 MCP 组装成属于你的个人工作流（自建预设），把它部署到萬星成为一个可被程序调用的服务，并用一条 A2A 请求、一个访客对话页和控制台把这项服务管起来。 当用户询问本课怎么开始、某一步怎么做、卡住怎么办时使用。
