# 星研·学院 · 萬星与谦面协作入门：搭起你的第一个个人工作流（伴学技能）

> 网页版课程：https://www.finddatatech.cloud/research/academy/wanxing-facet-workflow
> 本技能 = 课程的装包伴学版：装上它，助手即本课助教。**读者层 build**——由课程声明，与网页版一致。

## 伴学方式（给助手的说明）

- 按下文步骤推进：每步先讲清「做什么、为什么」，再引导用户动手；等用户确认完成，再进下一步。
- 用户卡住时，先请其描述屏幕上看到什么；界面细节以用户实际所见为准，不臆造界面元素。
- 每步末尾有一个**检查点**，用它向用户确认完成情况，不代用户跳过。
- 不要替用户做操作，也不要把结论直接告诉用户——本课的价值在用户自己走一遍。

## 排障时的处理顺序（给助手）

用户在某步卡住时，按下面三条处理，顺序不要颠倒：

1. **先定位，不猜**：请用户描述看到的现象（页面文案、按钮状态、有没有报错），对照本文末尾「如果没成功（给助手的兜底清单）」的条目逐条比对。
2. **能重试的就地重试**：网络类问题（页面打不开、跳转失败）通常等几分钟重试即可，先试这个。
3. **必须本人或管理员出面的，明确说出来**：凡涉及账号凭据、组织权限、市场连接的步骤，说明「这一步需要你本人操作」或「需要联系平台运维」，不要代做也不要含糊过去。

兜底条目由课程提供（见文末小节），本片段只规定处理顺序。

## 这门课的结果

把壹座里装好的技能与 MCP 组装成属于你的个人工作流（自建预设），把它部署到萬星成为一个可被程序调用的服务，并用一条 A2A 请求、一个访客对话页和控制台把这项服务管起来。

## 前置条件（与用户确认）

> 本课是「动手自建」层（进阶层）：面向想把工作流部署给程序调用的重度用户。如果你只想上手就用，先完成「上手就用」层的课程零与课程一，本课可以晚点来。

- 已完成课程一（或已熟悉壹座的功能集市场与追踪页），并完成《装上第一个功能集》。
- 平台账号；若要走「发布并部署」这条捷径，账号需在创作者组（creators）。
- 调用服务需要一枚调用键（`sk-` 开头的凭据，由平台提供），以及一个能发 HTTPS 请求的工具（`curl` 即可）。
- 手上还没有可部署的预设也不影响学习：萬星目录里的公开服务可以直接拿第 5 步的方法调用，调用侧动作完全一样。

## 步骤

### 1. 先分清三个面

- **谦面（facet）**是功能集市场与供给处：技能 + MCP 引用 + 角色（persona）组装成一个 pack（功能集），版本化发布。市场入口是 `facet.finddatatech.cloud`，技能与 MCP server 注册在 `mcp.finddatatech.cloud`。
- **壹座（platform）**是装配与自用面：订阅、安装功能集，在对话里使用它们，也能自建预设。
- **萬星（wanxing）**是服务面（`wanxing.finddatatech.cloud`）：把装配好的 agent 部署成服务，对外提供 A2A 调用、目录、访客对话页、控制台与用量。

一条服务的完整链路：谦面发 pack → 壹座订阅安装 → 部署 → 萬星暴露 A2A 接口 → 调用者用调用键调用 → 结算。

### 2. 用自建预设搭出你的工作流

设置 → 自建预设（`/settings/presets`）：把已装的技能与 MCP 选成子集，配一个 persona，这就是你的个人工作流。回到 `/chat`，用 agent 选择器选中它并提一条真实业务问题；去 `/trace` 确认它用的是你挑的那几个工具。

### 3. 把预设发布并部署为服务

预设行内有一个「发布并部署」：一键把预设发成 pack（需创作者组）并部署为 agent 服务——这是从「自己用」到「给别人用」的捷径。

也可以走标准入口：壹座 → 设置 → 功能集 → 打开功能集详情 → 带 serving 契约的 agent 会显示「部署为服务」按钮 → 填可选的节奏 / 预算覆盖、粘贴计费键 → 部署，约 5 分钟内生效。

- 计费键：部署时粘贴的 `sk-` 键是该 agent 跑回合时消耗模型资源的计费身份，由部署者承担；不填则沿用既有绑定。
- 部署完成后，同一页出现部署行：版本、在线 / 暂停状态、暂停 / 恢复按钮，以及「去配置」——直接跳到萬星控制台里的这个 agent。

### 4. 在萬星控制台看住它

控制台（`#/console`，需登录）：

| 面板 | 能做什么 |
| --- | --- |
| 机群板 | 全部 agent 状态总览（30 秒自动刷新） |
| 每 agent 时间线 | 该 agent 的最近事件，含延迟 |
| 部署管理 | 列出你的部署，暂停 / 恢复 |
| 调用者白名单 | 私有 agent 加 / 删调用者邮箱（公开 agent 不需要） |
| 服务配置 | 每个部署的节奏（rhythm）/ 回合预算（budget）/ 模型（model）读写 |
| 用量视图 | 谁调了我的 agent（调用记录） |
| 允许量 | 访客对话页的免费额度上限 |

### 5. 让程序调用它（A2A）

先拿 slug：`GET {BASE}/api/wanxing/v1/agents` 返回公开目录，slug 形如 `packs-<packId>-<agentId>`（全小写）。也可以先读 AgentCard：`GET {BASE}/api/wanxing/v1/a2a/{slug}/.well-known/agent-card.json`。然后发一个回合：

```bash
curl -X POST "https://wanxing.finddatatech.cloud/api/wanxing/v1/a2a/<slug>" \
  -H "Authorization: Bearer <调用键>" \
  -H "Idempotency-Key: my-$(date +%s)" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"message/send",
       "params":{"message":{"role":"user","parts":[{"kind":"text","text":"你好"}]}}}'
```

要点：

- 同步返回是回执（agent 的即时答复），长活发生在回合里；要流式就换 `message/stream`，响应是 SSE。
- 幂等：`Idempotency-Key` 只对 `message/send` 生效，24 小时重放窗——同键重放返回首次完整应答，不跑第二个回合、不产生第二条计费。
- 计费按时长：分钟向上取整 × 档位单价，回合结束即时结算到调用键；失败回合不计费。
- 并发：每（调用者, agent）同时只允许 1 个回合，超发得到 409 与 `Retry-After`，按提示重试。
- 常见错误码：401 键无效、402 余额不足 / 调用者被挂起、403 私有 agent 不在白名单、404 无此服务、409 回合进行中、423 agent 已暂停、429 触发限流、503 计费面不可用。

### 6. 给人一个对话入口

公开 agent：任何人打开 `https://wanxing.finddatatech.cloud/#/chat/<slug>`，登录即可聊。免费额度由你在控制台设的允许量承担；额度用完不会关闭页面，而是提示访客「可粘贴自己的调用键继续」，之后就走他自己的余额。私有 agent 需要先在调用者白名单里。

## 下一步

把工作流做成可共用的功能集：技能准备 → 注册进 registry → 组装 manifest 并过校验 → 发布到谦面 → 开通使用权限 → 验收。这条链路的完整配方见同市场官方功能集《平台指南》里的《谦面功能集制作指南》。用户装不上或用不了时，按四道闸排查：装包组门、registry scope、计费身份、市场凭据——最后一道必须用户本人去壹座连接 MCP 市场，管理员代不了。

配套谦面 pack：本课的双载体功能集在谦面市场（`facet.finddatatech.cloud`）上架后可获取，届时在壹座「设置 → 功能集」按课程名搜索即可订阅安装；市场地址将在 pack 发布后回填本页。

## 如果没成功（给助手的兜底清单）

- **没有可部署的预设**：不影响往下学。萬星目录里任意一个公开服务都能用第 5 步的方法调用，调用侧动作完全一样，先把调用练熟再回来部署自己的。
- **「发布并部署」按钮是灰的**：这条捷径要求账号在创作者组。找平台运维把自己加进创作者组；或者走标准入口（功能集详情页的「部署为服务」），两者效果相同。
- **点了部署但状态一直不变在线**：部署约 5 分钟生效，先在控制台机群板等一会儿；仍不在线就把该 agent 时间线上的报错发给平台运维。
- **调用返回 401 / 402 / 409 / 429 / 423**：按第 5 步返回码表对号入座——401 换键、402 充值或找运维恢复、409 等上一个回合结束、429 按等待时间重试、423 去控制台恢复。
- **访客页打不开**：先确认 agent 是公开的（私有 agent 要先把访客加进调用者白名单）；再确认额度，用完页面不会关，但会要访客粘贴自己的调用键。
