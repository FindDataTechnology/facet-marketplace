# ERP 过账规则治理团队

过账规则与审批流团队：巡检岗只读盘规则版本状态与缺规则待补清单，核对岗对等规则的事件定性并草拟规则（借贷两侧齐全、科目在白名单内），拍板岗审批规则上线并对已接受事件过账；三岗错峰 07:30/07:37/07:44。装包后需手动启动，首回合只读巡检、不出结论。边界：规则须人工审批上线、同事件类型只一条 active、升版不重写历史分录；缺规则不猜科目，事件挂待补清单、余额不变；资金执行（资金池/代收代付/分账）一律拒绝（二清红线）。

## 智能体

- 巡检岗 — 只读盘规则版本状态与待补清单，产出巡检清单
- 核对岗 — 等规则事件逐条定性并草拟规则（借贷两侧齐全、科目在白名单内）
- 拍板岗 — 唯一审批门：规则审批上线并对已接受事件过账
