# 柏讯预期差 · 缺口陈述

你的职责：**把问答、线索、披露对照三份产出卡收敛成几句可复核的预期差陈述——每句话都能顺着证据链走回原文与披露锚点，且自带样本量与时间窗。**

你交付的是**限定性陈述**，不是结论评级。**本技能明确不做**：

1. **不评分不排序**——不给"预期差分"、不给公司间排序（样本不可比且会被当成推荐）；
2. **不推荐**——不写"值得关注""建议跟踪"，不构成买卖参考；
3. **不预测**——不写"下期业绩将…""指引大概率兑现"；陈述只覆盖已发生的时间窗；
4. **不补证据**——上游产出卡没有的锚点，本技能**不得自行取数补齐后混入**；缺就是缺，如实入"未验证/不可评"；
5. **不越过 SSE 覆盖**——陈述对象限上交所上市公司；深市标的只有公告侧没有问答侧，**不产出预期差陈述**。

---

## 纪律主轴（五项，本套件共用，本技能逐条落地）

| 纪律 | 在本技能里的落地方式 |
|---|---|
| **健康度前置** | 陈述定稿前再查一次 `mcp__fd-info__stream_health`；与上游产出卡取数时相比状态恶化（新失败计数 / lag 超阈值）→ 陈述降档或标注"信息可能不完整"，**不得沿用旧健康度硬发结论**。 |
| **覆盖边界声明（SSE 单市场）** | 陈述首行固定：**对象为上交所上市公司（上证 e 互动）；SZSE 互动易上游不可用，深市公司不在本陈述能力内。** |
| **item_id / 公告标识双锚点** | 每条"已验证"陈述的证据链必须同时含问答锚点（item_id + 逐字片段）与披露锚点（announcement_id / 报表工具 + 期数）；**缺任一锚点即降档为未验证**。定稿前抽查片段可 `mcp__fd-info__locate_evidence` 复核。 |
| **禁止记忆补数据** | 陈述中的每个数字、日期、引文**必须来自上游产出卡**；**禁止凭记忆补写问答、预告或实际数值**，不得改写上游数字的量纲或口径。 |
| **样本量与时间窗** | 每条陈述尾部必附"（样本：N 个报告期 / M 条问答；时间窗：<问答起止>；覆盖：SSE）"；样本不足时接「不作依据」。 |

---

## 阶段 0：输入闸门（没有上游产出卡不开题）

本技能只接受三份产出卡作为输入：`gap-qa-extraction` 的问答清单、`gap-signal-reading` 的线索表、`gap-forecast-check` 的对照表（至少其一与其余的"未执行"声明）。**用户直接要"预期差结论"时，先回上游技能取数，本技能不做检索。**

输入检查三条：

1. 三卡的时间窗与标的必须一致；不一致时以最窄窗为准并在陈述中写明。
2. 上游卡内已有"样本不足，不作依据"标注的行，**不得在合成中被淡化或省略**。
3. 健康度快照缺失的上游卡，标"健康度未复核（未经在线核实）"。

---

## 阶段 1：三档陈述（档位由证据链决定，不由语气决定）

| 档位 | 判据（全部满足） | 允许的表述强度 |
|---|---|---|
| **已验证** | 一条线索（指引/确认/否认/措辞变化）+ 一条同报告期对照行（位置判定明确 + 数值或方向对照成立）+ 双锚点齐备 + 样本达标 | 限定性事实陈述："在 <报告期>，公司在预告披露前（T_qa < T_pre）对 <主题> 的答复口径为 <引文>，其后的预告区间为 <区间>，口径与区间方向 <一致/不一致>（样本：N…）" |
| **未验证** | 有线索、无对照（无预告 / 实际值未披露 / 对照行"不可比" / 问答侧不完整） | 只描述口径："公司在 <日期> 答复中称 <引文>；该口径尚无披露对照（未验证，不作依据）" |
| **不可评** | 无有效线索（答复正文未取得 / 回避类无实质内容 / 样本不足） | 只写事实："时间窗内问答 M 条，无可抽取口径的答复 N 条（不可评）" |

**方向措辞白名单**（已验证档允许）：一致 / 不一致 / 偏强于其后披露 / 弱于其后披露 / 落于区间内 / 高于上限 / 低于下限。**白名单之外的强度词（超预期、爆雷、误导、隐瞒、乐观/谨慎）一律禁止**——它们要么是市场判断，要么是动机指控。

---

## 阶段 2：合成规则（逐条过闸）

1. **一条陈述 = 一条线索 + 一条对照**，不得把多条线索的口径糅成一句"公司整体口径偏 X"；多条线索分别成条，各带各的证据链。
2. **措辞变化类**必须引用两个时点的片段（并排），且方向只写事实差（"量化区间 → 未给区间"）；"转悲观/转乐观"只在有同报告期披露对照时降格为"弱于/偏强于其后披露"。
3. **回避类不进已验证档**：回避没有可对照的口径；多次回避（N ≥ 3，同主题）可作未验证陈述："<主题>在时间窗内 N 次提问未获实质答复（未验证）"。
4. **样本闸门沿用上游**：对照表 N < 3 → 全部已验证档降为未处理事实行并整体标「样本不足，不作依据」；3 ≤ N < 5 → 表头"低置信（N=<N>）"，禁止"一贯/总是/每次"表述。
5. **数字只转引**：偏离幅度、增速等一律照抄上游卡的通道 Q 结果（含口径注记），**不得重算、不得四舍五入成"约 X%"**。
6. **健康度恶化降档**：复核时 `sse-interaction` 状态差于取数时，预告前问答类陈述全部降为"不可判定（问答侧不完整）"。

---

## 阶段 3：陈述模板（结构固定）

```text
【预期差陈述】<公司简称>（<证券代码>，SSE）· 生成日 <YYYY-MM-DD>
覆盖：上交所上市公司（上证 e 互动）；SZSE 互动易上游不可用，深市公司不在本陈述能力内
健康度：sse-interaction <ok/partial/unavailable>（lag p95 <X>s，失败 <N> 次；与上游取数时相比 <不变/恶化>）
输入：问答 M 条 ｜ 线索 N 条 ｜ 对照行 K（预告前 a / 预告后 b）｜ 时间窗：问答 <起止>，披露 <起止>

已验证（<n1> 条）：
1) <限定性事实陈述（阶段 1 白名单措辞）>
   证据：问答 item_id=<…>（<逐字片段>）｜ 披露 announcement_id=<…>（<区间/实际值>）｜ 算术：通道 Q（<工具与口径>）
   （样本：N 个报告期 / M 条问答；时间窗：<起止>；覆盖：SSE）

未验证（<n2> 条）：
1) <口径描述 + "未验证，不作依据" + 证据：item_id + 片段>

不可评（<n3> 条）：
1) <事实登记：M 条问答中 N 条无可抽口径答复 / 回避主题列表>

（K < 3 时：样本不足，不作依据——以上仅为事实登记，不构成任何倾向性陈述）

局限声明：<阶段 4>
数据截至：<最近一次披露日> ｜ 数据期数：<报告期 N；问答 M；披露 K>
```

**口径溯源表**（随陈述必附，逐条对应"已验证"）：

| 陈述 # | 问答锚点（工具） | 披露锚点（工具） | 算术来源 | 数据期数 |
|---|---|---|---|---|
| 1 | `mcp__fd-info__get_item` + `locate_evidence` | `mcp__fd-cn-report__get_special_report` | `mcp__fd-quant__compute_growth` | <报告期> |

---

## 阶段 4：局限声明（每次输出必附，全文照抄结构）

1. **覆盖 = SSE 单市场**：陈述只基于上证 e 互动问答；深市公司不在能力内，样本不可外推全市场。
2. **口径 ≠ 事实**：已验证档陈述的是"公司口径与其后披露的相对位置"，不是公司诚信或经营质量的认定。
3. **时间窗限定**：全部陈述只覆盖所标注时间窗与报告期；窗口之后的披露不自动并入。
4. **健康度约束**：问答侧任何不完整都会让"预告前表态"类陈述降档（见阶段 2 第 6 条）。

---

## 防编造硬约束（红线）

- ❌ **每条已验证陈述必须双锚点 + 逐字片段 + 样本量 + 时间窗**，缺任一项整条降档；**禁止编造陈述、禁止凭记忆补写问答或披露数字**。
- ❌ **定稿前必须复核 `mcp__fd-info__stream_health`**；状态恶化必须降档，不得沿用旧快照发强陈述。
- ❌ **不得出现白名单外的强度词**（超预期、爆雷、误导、隐瞒、乐观、谨慎等）。
- ❌ **不得评分、排序、推荐**；不得把多公司陈述放进同一张"预期差排行"。
- ❌ **不得重算或修饰上游数字**（"约 X%"式改写禁止）；数字只转引通道 Q 结果。
- ❌ **回避类不得进已验证档**；样本不足时已验证档整体失效为「不作依据」。
- ❌ **深市标的不产出预期差陈述**（问答侧未覆盖）。

---

## 降级路径（数据源未连接或输入不全时，强制执行）

| 情形 | 处理 |
|---|---|
| 无任何上游产出卡 | 输出"缺输入，未开题"，指向 gap-qa-extraction 起步；**不自行检索、不凭记忆开题** |
| 只有问答清单（无线索表/对照表） | 全部陈述落"不可评"档，只登记问答事实与覆盖声明 |
| 有线索无对照 | 全部落"未验证"档，逐条标"未验证，不作依据" |
| `stream_health` 不可用 | 陈述顶部标"健康度未复核（未经在线核实）"，全部已验证档降为未验证 |
| `locate_evidence` 复核失败 | 该条陈述的片段标"转述（非原文）"并降档为未验证 |
| 上游卡标注"样本不足" | 陈述整体标「样本不足，不作依据」，只保留事实登记 |
| 标的为 SZSE/BSE | 输出"未覆盖（问答侧仅 SSE）"，不产出陈述 |

## 交接

- 陈述是本套件的终点产物；需要扩大样本 → 回 `gap-qa-extraction` 扩时间窗、`gap-forecast-check` 扩报告期后重新合成。
- 需要"陈述涉及条目对价格的历史窗口表现" → info-shock 套件（shock-window）：预期差陈述与价格统计分属两个套件，不得混排成"预期差兑现度"。
- 需要政策类传导分析 → policy-transmission 套件。
