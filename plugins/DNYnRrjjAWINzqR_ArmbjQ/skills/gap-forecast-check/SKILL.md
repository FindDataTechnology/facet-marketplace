# 柏讯预期差 · 与业绩预告对照

你的职责：**把公司在互动平台上说过的话，放到它自己的披露时间轴上——问答在预告前还是预告后、说的口径与随后披露的预告区间和实际值对照是什么位置——并让每个数字可复核。**

你交付的是一张逐报告期的对照表，不是"预期差结论"。**本技能明确不做**：

1. **不合成预期差陈述**——"口径偏强/偏弱"的限定性结论属 `gap-statement`；本技能只给对照事实（时间先后 + 数值位置）；
2. **不读心**——不写"公司明知业绩差还在回避"这类动机推断；
3. **不做价格反应统计**——问答后的价格表现属 info-shock 套件；
4. **不心算**——任何偏离幅度、增速差的算术一律传值给通道 Q（fd-quant），**不得由模型手算或估算**；
5. **不跨市场对照**——问答覆盖仅 SSE；深市公司即使有业绩预告，也没有问答侧，**不进入对照表**。

---

## 纪律主轴（五项，本套件共用，本技能逐条落地）

| 纪律 | 在本技能里的落地方式 |
|---|---|
| **健康度前置** | 对照前先 `mcp__fd-info__stream_health`；`sse-interaction` 非 ok 或 lag 超阈值（默认 1800 秒）→ 顶部声明"信息可能不完整（问答侧可能缺最新条目）"。**问答侧缺条目时不得把对照写成"公司在预告前未表态"。** |
| **覆盖边界声明（SSE 单市场）** | 每次输出必附：**问答覆盖 = 上交所上市公司（上证 e 互动）；SZSE 互动易上游不可用。** 对照表只含 SSE 标的；深市标的只有公告侧没有问答侧，不进对照。 |
| **item_id / 公告标识双锚点** | 问答侧锚 `item_id`，公告侧锚 `announcement_id`（`list_filings` / `get_special_report` 返回）；**两个锚点缺一，该行对照不得进入正式表**。 |
| **禁止记忆补数据** | 预告区间、实际值、披露日期**必须来自工具返回**；**禁止凭记忆补写、编造任何一期的预告或实际数值**。 |
| **样本量与时间窗** | 每张对照表必附：报告期数（样本量）、时间窗（问答起止 + 披露起止）、覆盖（SSE）；**单报告期单条问答的对照标"单例，不作依据"**。 |

## 阶段 0：输入与通道分工（越线即硬失败）

输入应为 `gap-qa-extraction` 的问答清单与 `gap-signal-reading` 的线索表（至少指引类/措辞变化条目）；**没有输入时先回上游技能取数。**

| 环节 | 通道 | 工具 |
|---|---|---|
| 问答时间点与健康度 | **通道 A（info-stream）** | `mcp__fd-info__list_since` / `get_item` / `stream_health` |
| 业绩预告/快报（区间与披露日） | **通道 A（公告面）** | `mcp__fd-cn-report__get_special_report`（category 必填） |
| 实际值（定期报告/业绩快报） | **通道 A（公告面）** | `mcp__fd-cn-report__get_financial_statements` / `get_special_report` |
| 定期报告披露日与原文 | **通道 A（公告面）** | `mcp__fd-cn-report__list_filings` / `get_filing` |
| 主体锁定 | **通道 A（公告面）** | `mcp__fd-cn-report__get_company` / `get_sse_company` |
| 数值对照算术 | **通道 Q（不取数）** | `mcp__fd-quant__compute_growth` |
| 样本闸门 | **通道 Q** | `mcp__fd-quant__check_observation_sufficiency` |

**两条纪律**：披露侧数值只走公告面工具；对照算术只走通道 Q。**任何一侧都不接受模型记忆。**

---

## 阶段 1：三段时间轴（每个报告期一条轴）

对每个报告期（如 2026 中报、2026 三季报），按披露顺序排三段时间：

| 节点 | 符号 | 来源 | 口径 |
|---|---|---|---|
| 问答发布 | **T_qa** | `list_since` 条目 `published_at` | 问答条目的发布日；同报告期多条问答时全部列出，不合并 |
| 预告披露 | **T_pre** | `get_special_report(category="业绩预告")` 的 `published` | 预告公告披露日；无预告的报告期如实标"无预告" |
| 实际值披露 | **T_act** | `list_filings`（定期报告）或 `get_special_report(category="业绩快报")` 的 `published` | 实际值首次正式披露日 |

时间轴的两个关键位置判定（决定对照含义，必须写明）：

1. **T_qa < T_pre（预告前问答）**：公司在预告发布前对业绩相关提问的答复口径，与**其后的预告区间**对照——这是预期差的主动线（公司在正式预告前怎么表表态）。
2. **T_qa > T_pre（预告后问答）**：答复口径与**预告区间或已披露实际值**对照——这是追问线（投资者对已披露数字的质疑与公司回应）。

**同日不可判定先后**：T_qa = T_pre 时标"同日，先后不可判定"，该条不进入位置判定，只登记。

## 阶段 2：对照表（逐报告期一行）

| 字段 | 必填 | 说明 |
|---|---|---|
| 报告期 | 是 | 如 2026H1；口径原样 |
| T_qa / T_pre / T_act | 是 | 三个日期 + 位置判定（预告前/预告后/同日/无预告） |
| 问答锚点 | 是 | item_id + 线索类型（来自 gap-signal-reading）+ 逐字片段 |
| 预告锚点与区间 | 有预告必填 | announcement_id + 区间（下限/上限，中值口径写明；金额单位原样） |
| 实际值锚点与数值 | 已披露必填 | announcement_id / 报表工具名 + 数值与单位 |
| 数值对照结果 | 两侧齐备时必填 | 通道 Q 算出的口径位置（见阶段 3）；**不自算** |
| 数据期数 | 是 | 本行涉及的时间窗 |

**对照只在"口径可比"时做数值位**：答复口径（定性表述如"预计增长"）与预告区间对照时，结果只能是**定性位置**（"口径与预告方向一致/不一致/不可比"）；只有答复或线索里出现**具体数值**、且与预告/实际值同指标同单位时，才做数值对照。**不可比的行标"不可比（口径不同：<原因>）"，不得强行折算。**

---

## 阶段 3：数值对照只走通道 Q

1. **增速对照**：把各期数值组成序列（指引口径值、预告中值、实际值分别成列）传 `mcp__fd-quant__compute_growth`，取同比/环比增速再对位置；**增速不得手算**。
2. **偏离幅度**：实际值相对预告区间（下限/上限/中值三个口径**并列**，不得只对中值）的偏离，以通道 Q 返回的算术结果为准；输出写明"相对 <口径> 的偏离为 <值>（通道 Q 计算）"。
3. **样本闸门**：报告期数 N（= 对照表行数）先过 `mcp__fd-quant__check_observation_sufficiency`；N < 3 → 整表标注**「样本不足，不作依据」**，只列事实行；3 ≤ N < 5 → 表头标"低置信（N=<N>）"，禁止"一贯/总是"表述。
4. **预告是区间估计**：对照表述必须保留区间（"实际值落于区间内 / 高于上限 / 低于下限"），**不得把"落在区间内"写成"符合预期"**——预期是市场概念，本技能只对披露口径。

---

## 阶段 4：局限声明（每次输出必附）

### 4.1 问答覆盖 = SSE 单市场（固定声明）

问答侧只覆盖上交所上市公司；深市公司不进对照。**"SSE 样本上的对照结果"不得外推为全市场规律。**

### 4.2 对照 ≠ 因果

时间先后（公司在预告前说了 X，预告为 Y）只是事实顺序；**不得写"公司误导""预告被问答提前泄露"**——问答与预告的关系是对照对象，不是指控材料。

### 4.3 预告与实际值的口径差

业绩预告（区间估计）、业绩快报（初步数）、定期报告（审计口径）三者数字可能不同；实际值默认取**最新披露口径**并写明取自哪一层；口径变化（快报数与年报数不一致）在表内单列一行说明，**不得静默取其一**。

### 4.4 问答侧的可见性受健康度约束

`sse-interaction` 源 lag 超阈值或 partial 时，预告前问答可能缺最新条目；此时"预告前无表态"类位置判定全部降级为"不可判定（问答侧不完整）"。

## 防编造硬约束（红线）

- ❌ **预告区间、实际值、披露日期必须来自工具返回**；无返回写"未取得"，**禁止编造、凭记忆补写任何一期的预告或实际数值**。
- ❌ **对照前必须先查 `mcp__fd-info__stream_health`**；问答侧不完整时位置判定降级为"不可判定"，不得写成"预告前未表态"。
- ❌ **深市标的不得进入对照表**（问答侧未覆盖）；不得把 SSE 样本表述为全市场。
- ❌ **数值算术只走通道 Q**（`compute_growth`），偏离与增速不得由模型心算或估算。
- ❌ **预告区间三口径并列**（下限/上限/中值），不得只对中值下结论；"落在区间内"不得写成"符合预期"。
- ❌ **同日不可判定先后**；无预告的报告期如实标"无预告"，不得用问答口径冒充预告。
- ❌ **不得由对照推出动机**（误导、隐瞒、泄露类表述一律禁止）。
- ❌ **单例不外推**：N < 3 整表标注「样本不足，不作依据」。

## 降级路径（数据源未连接或调用失败时，强制执行）

| 情形 | 处理 |
|---|---|
| `fd-info` 未连接/报错 | 问答侧标"未连接（未经在线核实）"，对照表降级为**纯披露时间轴**（T_pre/T_act 照出，问答列全空并声明）；**不得用记忆补问答** |
| `get_special_report` 不可用 | 预告列标"未取得"；对照降级为"问答 vs 实际值"两段轴，声明缺预告层 |
| `get_financial_statements` 不可用 | 实际值列标"未取得"；对照降级为"问答 vs 预告"，声明实际值未核 |
| `compute_growth` 不可用 | 数值对照列全部标"未计算（通道 Q 未连接）"，只给原始数值与区间事实；**不得改由模型手算** |
| `check_observation_sufficiency` 不可用 | 以表内 N 人工标注样本档位，并声明"闸门未过计算面校验" |
| sse-interaction=unavailable | 问答侧整体标"来源不可用"，**不产出对照表**（只剩披露时间轴时按第一行降级处理） |
| 标的为 SZSE/BSE | 输出"未覆盖（问答侧仅 SSE）"，不检索、不对照 |

## 交接

- 对照表 + 线索表 + 问答清单 → `gap-statement`：由它把"时间先后 + 口径位置 + 样本量"合成为限定性预期差陈述。
- 需要"问答后的价格窗口表现" → info-shock 套件（shock-window）：本技能不给任何价格侧数字。
- 需要更长的报告期序列 → 扩 `list_filings` 年份范围（逐年取），回本技能重跑阶段 1–3。
