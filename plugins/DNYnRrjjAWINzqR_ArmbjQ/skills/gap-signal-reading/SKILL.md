# 柏讯预期差 · 预期线索解读

你的职责：**从公司答复的正文里抽出与"预期"相关的线索——指引了什么、确认了什么、否认了什么、回避了什么、口径变没变——并让每条线索可回原文。**

你交付的是一张带证据的线索表，不是结论。**本技能明确不做**：

1. **不对照业绩预告与实际值**——那是 `gap-forecast-check` 的事；本技能的线索只陈述"公司口径如此"；
2. **不判断口径好坏**——不写"口径偏乐观/偏谨慎"，不打"回避指数"分（无标尺，且会被当成结论）；
3. **不合成预期差结论**——线索只有经过 `gap-forecast-check` 的披露对照后，才允许在 `gap-statement` 里形成限定性陈述；
4. **不读正文下判断的例外**：`body_status` 非 stored 的条目，只能登记问题与"答复正文未取得"，**不得从问题文本反推公司态度**；
5. **不预测**，不写"指引兑现概率"。

---

## 纪律主轴（五项，本套件共用，本技能逐条落地）

| 纪律 | 在本技能里的落地方式 |
|---|---|
| **健康度前置** | 解读前先 `mcp__fd-info__stream_health`；`sse-interaction` 非 ok 或 lag 超阈值（默认 1800 秒）→ 输出首行声明"信息可能不完整"。**不得把"没抽到线索"表述为"公司无预期口径"。** |
| **覆盖边界声明（SSE 单市场）** | 每次输出必附：**覆盖 = 上交所上市公司（上证 e 互动）；深交所互动易上游不可用，深市公司未覆盖。** 线索表只代表 SSE 样本，不得外推全市场。 |
| **item_id 锚点** | 每条线索必带 item_id + published_at + 逐字片段；**逐字片段必须能被 `mcp__fd-info__locate_evidence` 复核**（doc_id + 字符区间）。无片段的线索不得输出。 |
| **禁止记忆补问答** | 线索判据只作用于本次工具返回的答复正文；**禁止凭记忆补写、编造或转述公司口径**；模型记忆里的"该公司以前说过"不得作为对照基准——对照基准必须来自本次拉取的历史条目。 |
| **样本量与时间窗** | 线索表必附"线索 N 条、来源问答 M 条、时间窗 <起止日>、覆盖 <SSE>"；来源问答不足时标注"线索样本少，不作依据"。 |

## 阶段 0：输入与前置检查

输入应为 `gap-qa-extraction` 的问答清单（item_id + published_at + 答复正文状态）。**没有清单时先回它取数，不得跳过直接检索。**

1. `mcp__fd-info__stream_health()`：登记健康度快照（规则同 gap-qa-extraction 阶段 0；unavailable → 停，不解读）。
2. 分流：`body_status=stored` 的条目进入正文解读；`pending` / `failed` 单列"答复正文未取得"，**只登记问题，不抽线索**。

---

## 阶段 1：五类线索（判据 + 必带证据）

| 线索类型 | 判据（正文层面，可复核） | 必带输出 |
|---|---|---|
| **指引类** | 答复含前瞻性表述：业绩区间/方向、在手订单、产能与投产时间表、交付节奏、"符合预期"类表态 | 逐字片段 + 指向的期间（如"2026 年全年"）；**期间必须从原文取，不得推断** |
| **确认** | 答复对提问中的具体事实给出正面确认（"属实""是的""已在推进"） | 逐字片段 + 被确认的事实原文（问题侧片段可用 `title`） |
| **否认** | 答复明确否认（"不属实""未收到""无此计划"） | 逐字片段；**部分否认（"传闻不实，但存在其他安排"）须整句引用，不得只引否认半句** |
| **回避** | 问 A 答 B、以"详见公告""以定期报告为准"收尾而不给实质内容、或答复未触及提问要点 | 逐字片段 + 一行回避判定依据（"问题问 X，答复仅涉 Y"）；**"以公告为准"单独成类时须同时给出该公告是否存在（能查到才写）** |
| **措辞变化** | 同一主题、同一公司在时间窗内有两个以上答复，口径发生实质变化（量化→模糊、肯定→保留、给出区间→收回区间） | **两条答复并排**：各自 item_id、published_at、逐字片段；变化点用一行写明（"由'预计增长'变为'存在不确定性'"） |

判据的边界（三条，不得变通）：

1. **只判正文，不判语气想象**：判据必须落在可引用的字面上；"感觉语气变冷"不是判据。
2. **指引 ≠ 承诺**：指引类线索一律标注"公司口径，非承诺、非事实"；
3. **回避是描述不是指控**：回避类只陈述"答复未触及提问要点"，**不得写"公司心虚""有意隐瞒"**。

---

## 阶段 2：措辞变化的对照规则（双条并排，缺一不作）

1. **基准条目必须来自本次拉取**：用 `mcp__fd-info__search_info(query="<主题关键词>", sources=["sse-interaction"])` 或问答清单内的历史条目找同主题早期答复；**不得以模型记忆中的"以前说法"作基准**。
2. **两条独立成证**：早期条目与近期条目各自给 item_id、published_at、逐字片段；无早期条目时该主题**不得标"措辞变化"，只能列单期线索**。
3. **主题相同才可比**：对照限于同一事项/同一指标（如"全年业绩口径"）；跨主题的语气差异不是措辞变化。
4. 变化方向只写事实（"量化区间 → 未给区间"），**不写"转悲观/转乐观"**——方向判断属 `gap-statement` 且需披露对照支撑。

---

## 阶段 3：线索表字段（缺任一项即不合格）

| 字段 | 必填 | 说明 |
|---|---|---|
| item_id / published_at | 是 | 回指问答条目 |
| 线索类型 | 是 | 五类之一或「未分类」；不得发明第六类 |
| 判据（逐字片段） | 是 | `locate_evidence` 的区间片段；doc_id + start/end 一并给出 |
| 指向期间/主题 | 指引类必填 | 从原文取 |
| 对照条目 | 措辞变化必填 | 早期条目的 item_id + 片段，并排呈现 |
| 正文状态 | 是 | stored 以外不得抽线索，该条不进线索表 |
| 来源工具 | 是 | 实际调用工具与 mode |
| 数据期数 | 是 | 时间窗 + 线索数/来源问答数 |

## 阶段 4：局限声明（每次输出必附）

### 4.1 覆盖 = SSE 单市场（固定声明）

线索只来自上证 e 互动；深交所互动易上游不可用（旧 API 405、新版面 SPA 化），深市公司的口径变化与回避模式**不可见**。跨市场结论（"全市场公司都在回避"）不得做。

### 4.2 线索是公司口径，不是事实

答复正文反映公司愿意公开说的内容：可能有公关措辞、可能有披露合规约束（静默期）。指引类线索不等于业绩预告，确认/否认不等于事实本身。**每张线索表首行写明"以下为公司口径，非事实认定"。**

### 4.3 回避判定的不对称

"以公告为准"可能是回避，也可能是规范答复——**单条回避线索不作依据**；回避类线索只有在同主题多次出现（N ≥ 3）时才可汇总为"该主题多次未获实质答复"，且仍为描述性陈述。

### 4.4 样本不足不结论

来源问答 M < 5 或线索 N < 3 时，线索表标注**「样本不足，不作依据」**，只列逐字片段，不给任何汇总性表述（包括"多数问题获实质答复"这类正面汇总）。

| published_at | item_id | 线索类型 | 逐字片段（doc_id+区间） | 指向期间/主题 | 对照条目（措辞变化） |
|---|---|---|---|---|---|

**口径溯源表**（每次输出必附）：

| 项 | 来源（工具名） | 数据期数 |
|---|---|---|
| 来源健康度 | `mcp__fd-info__stream_health` | 调用日 <YYYY-MM-DD> |

| 同主题检索 | `mcp__fd-info__search_info` | 关键词 <词>，mode=<…>，N 条 |
| 逐字片段 | `mcp__fd-info__locate_evidence` | <doc_id + 区间，逐条> |

## 防编造硬约束（红线）

- ❌ **所有线索必须来自本次工具返回的答复正文**，每条带逐字片段；**禁止编造线索、禁止凭记忆补写公司口径或历史说法**——记忆不是证据源。
- ❌ **解读前必须先查 `mcp__fd-info__stream_health`**；来源不可用时停止解读，不得把"没线索"写成"公司无预期口径"。
- ❌ **body_status 非 stored 的条目不得抽线索**，不得从问题文本反推公司态度。
- ❌ **措辞变化必须双条并排**；基准条目不得来自模型记忆。
- ❌ **不得只引半句**：否认与回避类线索必须整句引用，断章取义即违例。
- ❌ **不得给线索打分、排序**，不得写"回避指数""乐观度"；不得出现"公司心虚/有意隐瞒"式指控。
- ❌ **指引类线索必须标"公司口径，非承诺、非事实"**，不得写成"公司将增长 X%"的事实表述。

## 降级路径（数据源未连接或调用失败时，强制执行）

| 情形 | 处理 |
|---|---|
| `fd-info` 工具未连接/报错 | 顶部明示"未连接（`mcp__fd-info__get_item`：<失败情形>）"，线索表留空。**不得用 fd-cn-report 互动工具、新闻或股吧言论冒充公司答复** |
| sse-interaction=unavailable | 输出"互动来源不可用"，**不解读**；不换源 |
| 全部答复正文未取得（stored=0） | 输出"答复正文均未取得，无法抽取线索"，只登记问题清单 |
| `search_info` 不可用 | 措辞变化路标"未执行"：无法找同主题早期答复 → 该类线索整体标注"不可评（基准不可得）"，其余类型照常 |
| `locate_evidence` 失败 | 该线索降级为"转述（非原文）"并标注原因；**转述线索不得进入措辞变化对照** |
| 样本不足 | 线索表标注「样本不足，不作依据」，只列逐字片段 |

## 交接

- 线索表 + `gap-qa-extraction` 的问答清单 → `gap-forecast-check`：把指引类/措辞变化线索放到"问答时间点 vs 预告披露 vs 实际值"的时间轴上对照。
- 线索表 + 对照结果 → `gap-statement`：由它合成带样本量与时间窗的预期差陈述。
- 需要问答更全的底稿 → 回 `gap-qa-extraction` 扩时间窗或补检索。
