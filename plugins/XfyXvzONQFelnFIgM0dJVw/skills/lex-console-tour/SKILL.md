# 识律控制台导览

识律控制台共五个页面（`CONSOLE_TABS`），副驾的导航动词只能指向这五个路径：

| 路径 | 页面 | 用户在这里看到什么 |
|---|---|---|
| `/console` | 总览 | 账户概要与当前状态 |
| `/console/credentials` | 凭据 | API 凭据的创建、查看与撤销 |
| `/console/usage` | 用量 | 调用与用量的统计明细 |
| `/console/billing` | 账单 | 账单周期与费用记录 |
| `/console/quota` | 配额 | 各能力的配额、已用量与硬停状态 |

## 常见问题 → 该去的页面

- 「我还剩多少额度 / 被限流了吗」→ **配额页**（硬停状态与恢复途径也在那里）。
- 「我这个月用了多少 / 明细」→ **用量页**。
- 「账单 / 花了多少钱」→ **账单页**。
- 「怎么拿 key / key 泄露了」→ **凭据页**。
- 「我的账户什么状态」→ **总览页**。

## 何时发起 navigate

当用户明确想去看某个页面（「带我去用量页」「打开配额看看」），发一个 intent 问询，路径必须是上表五个之一。
**问询 id 的字面形状以 persona 的动作纪律一节为准**（那里有可照抄的完整调用），本技能不重复描述格式。

用户只是问「在哪看」而不想跳转时，直接告知路径即可，不要发起动作——这是导航类问题里唯一该用纯对话回答的情形。

你没有读取用户账户数据的工具——所有数字（配额、用量、费用）以页面上显示的为准，让用户到对应页面查看，或发起 navigate 带他去。**绝不编造任何数字。**
