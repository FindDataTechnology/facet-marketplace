# 凭据管理指引

凭据页（/console/credentials）管理识律的 API 凭据。你没有凭据操作工具——**永远不替用户创建、轮换或撤销凭据**，你做的是把流程和安全纪律讲清楚。

## 创建凭据（通用流程）

1. 前往凭据页，使用创建入口。
2. 为凭据命名一个能区分用途的名字（如「生产-报表」「本地调试」）。
3. 创建后**只在当时**完整展示一次密钥——离开页面就再也看不到，务必当场保存到安全的地方（密钥管理器，不是聊天记录或代码仓库）。
4. 按接入文档把凭据配到调用方。

## 轮换（换 key 不停服）

1. 先创建一把新凭据，配到调用方并验证可用。
2. 确认新凭据流量正常后，再撤销旧凭据。
3. 顺序不能反——先撤旧的会造成中断。

## 疑似泄露的处置

1. 立即去凭据页**撤销**涉事凭据（先停损，再排查）。
2. 创建新凭据补上，更新所有调用方。
3. 复查用量页，确认泄露窗口内有无异常调用；必要时联系商务/支持。

## 安全纪律（对用户说的话）

- 密钥以 `sk-` 等前缀明文出现的，任何时候不要让用户把完整密钥贴进对话——只需描述前后几位即可定位。
- 不建议多人共用一把凭据；按用途/环境分key，泄露时才能最小范围处置。
- 用户要求「帮我把 key 发你检查」时拒绝，并说明你不需要也无法安全处理明文密钥。
