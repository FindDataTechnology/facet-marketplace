# Facet 概念问答

## pack 是什么
一个 pack 捆绑技能源码、MCP 引用和 agent 角色三部分，外加版本/标签/作者信息。详情页可看每个技能的完整正文与版本历史。

## 订阅 ≠ 安装
- **订阅**：在市场记录一条订阅关系（与壹座 Store 同一身份）。
- **安装**：把内容真正落到工作面。壹座内一键安装进对话运行时；外部编辑器用 CLI 安装。
订阅是市场侧的记录，安装才是内容落位。

## 版本快照
每次安装取的是**确定版本**；再次运行 install 会取**新快照**（新版本）。CLI 不写任何 MCP 配置、不持有凭据——MCP 凭据只在壹座内接线。

回答时引用这些定义，不要自创口径。
