# 识律 · 劳动法套件

劳动争议全流程 + 双计算器（识律×柏讯双线合流）：劳动仲裁全流程（申请书/答辩书/证据目录/一裁终局判断/时限表，含裁判者分支）为入口技能，劳动补偿金计算器与人身损害赔偿计算器为两个原子技能。法律依据走识律条级引用解析与效力核验，赔偿/补偿的统计基数走柏讯分省分年统计读取并强制 provenance（计算公式 + 基数来源 + 年份），统计源不可用或概念码未定档时中止数值计算。

## 技能

- labor-arbitration-workflow — 劳动争议仲裁全流程（识律劳动法套件入口技能）。当用户描述劳动争议案情（违法解除/经济补偿/加班费/未签合同二倍工资/调岗降薪/工伤待遇）、要求仲裁申请书或答辩书、证据目录、一裁终局判断、仲裁时限表，或以裁判者身份要求争议焦点归纳与裁决说理时使用。按立场（申请人/被申请人/裁判者）推进八阶段流程，并按需点名套件内两个计算器技能。
- labor-compensation-calculator — 劳动补偿金与经济补偿金计算器（识律劳动法套件原子技能，双计算器之一）。当用户要求计算解除劳动合同经济补偿 N、违法解除赔偿金 2N、代通知金 N+1、未签书面劳动合同二倍工资差额、加班费、未休年休假工资报酬，或需要判断三倍封顶（社平工资三倍 × 12 年上限）时使用。法律依据走识律条级解析，数值基数走柏讯统计源，每个结果强制附公式与基数来源。
- personal-injury-calculator — 人身损害赔偿计算器（识律劳动法套件原子技能，双计算器之一）。当用户要求计算人身损害赔偿项目时使用——医疗费、误工费、护理费、交通费、住院伙食补助费、营养费、残疾赔偿金、残疾辅助器具费、丧葬费、死亡赔偿金、被扶养人生活费、精神损害抚慰金。法律依据走识律条级解析，残疾/死亡赔偿金等基数走柏讯统计源，每个结果强制附公式与基数来源。
