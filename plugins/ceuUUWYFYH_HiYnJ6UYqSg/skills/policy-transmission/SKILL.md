# 柏讯政策传导 · 区域与企业传导检验

你的职责：**对映射阶段交来的每一条"政策要素 → 检验变量"假设，逐环做统计检验，并把结果分成三档如实呈现：已验证、不显著、未验证环节。**

政策传导叙事最容易犯的错："国家出了补贴政策，所以行业起来了。"**有没有发生、幅度多大、时滞多长，三个问题没有一个能靠叙事回答。** 所以每一环都要有政策锚点、一条序列、一个窗口、一个样本量。

---

## 阶段 0：能力边界与用词纪律（开场必读）

### 0.1 本稿可做什么

| 可做 | 说明 |
|---|---|
| 事件窗比较 | 政策发布前后各 N 期的变量水平/增速对比（时点型政策） |
| 单环相关 | 政策强度代理序列与检验变量的相关（带样本量） |
| 时滞扫描 | 政策序列错位 k 期逐 k 求相关，输出整张滞后表 |
| 分组差异 | 政策适用组 vs 非适用组的变量差异（`compute_grouped_returns`） |
| 样本闸门 | 检验前先问"这段历史够不够"（`check_observation_sufficiency`） |
| 稳健性 | walk-forward 切窗，看时滞是否在样本外仍成立 |

### 0.2 本稿不可做什么（硬边界）

> ⚠️ **边界声明（每次输出的结论前置位复述要点）**
>
> 1. **不做因果推断。** 本稿只做相关、时序错位与前后窗对比。"传导"在本稿中仅指**统计上的联动与时序关系**，不是因果机制。全篇不得出现"因为政策所以增长"这类因果句。
> 2. **不做预测、不出投资候选。** 检验通过不等于未来仍成立；不给方向建议、不推荐标的。
> 3. **不报 p 值。** 计算面不输出 p 值；本稿用**检验前声明的阈值**判定，并写明"按预设阈值判定，非正式显著性检验"。**不得编造 p 值。**
> 4. **不补缺失、不插值、不向高频展开**来凑样本量。年鉴缺年就是缺年，样本量按实际配对数报。
> 5. **不用未验证环节凑结论。** 无数据的一环只能标「未验证环节」，不得默认成立。

## 阶段 1：输入契约（映射交来的东西必须先过这一关）

`policy-mapping` 交来的每条映射应长这样：

```
政策要素：<机关 + 工具 + 范围>（item_id=<…> ｜ as_of=<published_at> ｜ 引用「…」）
检验变量：<变量名>｜code <code>｜面板 <年鉴/城市/公司>｜频度 <年/…>｜覆盖 <起止>
置信度：<政策明示 / 语义推断> ｜ 方向假设：<正向/负向/中性>
```

**输入不合格的四种情形，逐一处理，不得自行补全**：

| 情形 | 处理 |
|---|---|
| 政策侧无证据块（正文未核实） | 该环 `未验证环节（政策正文未核实）` |
| 变量无 code（未在册检索） | 回 `policy-mapping` 补检索；补不到 → `未验证环节（无变量）` |
| 变量覆盖不含政策生效期 | `未验证环节（覆盖未及政策期：变量止于 <期>，政策生效 <期>）` |
| 政策已撤回 | 不检验，登记"政策已撤回" |

## 阶段 2：两条检验路线（先声明用哪条，不得混用）

### 2.1 路线一：事件窗（时点型政策，默认）

适用：一次性发布/生效的政策（规划印发、补贴办法施行）。

1. **T0 = 政策生效时间**（要素表载明；未载明生效条款时用 published_at 并注明"以发布日代生效日"）。
2. 取 T0 前后各 N 期的变量序列（年频默认前后各 3 期；城市面板年频同；公司面板年频同）。
3. 报告前后窗的水平与增速（**计算走通道 Q**：序列传 `mcp__fd-quant__summarize_return` 或 `compute_factor_exposure` 做前后段斜率对比），并给出**样本量**（= 进入前后窗的区域数 × 期数，写清计数单位）。
4. **对照组优先**：政策明示适用范围时，用非适用区域/行业作对照（`mcp__fd-quant__compute_grouped_returns` 分组），双组数字并列；**无对照组时必须声明"无对照，前后差异可能含共同趋势"**。

### 2.2 路线二：政策强度序列（连续型政策）

适用：可构造强度代理的政策（补贴金额年度序列、税率序列、政策条目累计数）。

1. 强度代理的构造口径必须写清（哪个变量、哪段聚合、什么单位），且**来源工具与期数随行**。
2. 强度序列与检验变量做同期相关 + 时滞扫描（同 chain-transmission 口径，见阶段 4）。

**同一份输出内一条环只用一条路线**；两条都跑时并列报告，不得择优。

## 阶段 3：频度对齐与样本闸门

| 频度组合 | 对齐方式 | 必须写进输出 |
|---|---|---|
| 同频（年–年） | 按同期匹配 | 配对数 = 期别交集 |
| 月/季频政策序列 + 年频面板 | 政策侧按**年均**聚合为年值 | "政策侧由 X 频聚合为年频，口径 = 年内算术平均" |
| 年频政策 + 季/月频变量 | 只能把变量聚合为年频，或标未验证 | **不得把年值复制到各季度**（人为放大样本量） |

**样本闸门**（检验前跑，结果写进输出）：

```text
mcp__fd-quant__check_observation_sufficiency(dates=<期别轴>, as_of=<口径日>,
    values=<序列>, required_observations=<门槛>)
mcp__fd-quant__check_series_as_of_bounds(dates, values, as_of)
```

门槛按频度预先声明：年频 **8**（年鉴面板默认）、季频 12、月频 24。`sufficient=false` → 该环 `未验证环节（样本不足：可用 X < 门槛 Y）`，**不得缩窗口硬算**。

## 阶段 4：逐环检验（相关与时滞）

### 4.1 同期相关与时滞扫描

```text
mcp__fd-quant__compute_information_coefficient(
    dates=<对齐后期别轴>, factor=<政策侧序列>, forward_returns=<检验变量序列>,
    as_of=<口径日>, method="spearman", min_observations=<阶段 3 门槛>)
```

- 返回用 `ic`（相关系数）、`n_observations`（实际配对数）、`n_dropped`。**pearson 与 spearman 同时给时并列呈现，不得只报好看的那个。**
- 时滞扫描：对 k = 0…K 逐期错位各调一次（年频默认 K = 0–3；月频 0–12）。**整张滞后表都要交**，不得只报最优 k；用最优 k 下结论必须补 `mcp__fd-quant__split_walk_forward_windows` 样本外验证。
- 需要弹性读数时用 `mcp__fd-quant__compute_factor_exposure`（α/β/t_beta/R²/n）；**t 值不是 p 值，原样报，不改写**。

### 4.2 判定规则（跑之前声明，不得看结果再定）

| 判定 | 条件（默认阈值，可配但须预先声明） |
|---|---|
| **已验证** | \|r\| ≥ 0.30 且 n ≥ 门槛，且相邻 2 个 k 上符号一致；或事件窗前后差异在对照组存在且方向一致 |
| **不显著** | n ≥ 门槛但 \|r\| < 0.30；或符号在相邻 k 上反复翻转；或前后差异无对照组且幅度低于序列自身波动（`mcp__fd-quant__summarize_volatility` 参照） |
| **未验证环节** | 任一侧不可得 / 样本不足 / 覆盖未及政策期 / 正文未核实 / 频度无法不造数据地对齐 |

**"已验证"只有一个含义：通过了检验前声明的阈值。** 它不表示因果成立，不表示政策效果确认，更不表示未来仍成立。

**多重检验必须自曝**：共执行 N 次相关/对比检验，结论旁注明"多重比较下，孤立的高相关可能是偶然"。

## 阶段 5：结论纪律（3.2.2 硬约束，gate 断言对象）

**传导结论必须区分「已验证」与「未验证环节」；相关系数与样本量随结论输出。** 每条结论的固定格式：

```
环节：政策 <机关+工具>（item_id=<…>，as_of=<…>）→ 变量 <code>（面板 <…>）
判定：已验证 / 不显著 / 未验证环节
统计：r=<相关系数>（method=<…>）｜ n=<样本量> ｜ 窗口 <起止> ｜ 时滞 k=<…>（若扫描）
对照组：<有（差异 <…>）/ 无（前后差异可能含共同趋势）>
解读边界：历史统计关系，非因果证明
```

**五条不容商量的规则**：

1. **「未验证环节」不得被"合理推测"顶替。** 不许写"虽然数据不可得，但从政策逻辑看应当传导到 X"。
2. **不得用相邻环节的结论替代**（A→B 未验证，不能拿 B→C 的已验证反推 A→B）。
3. **不显著就写不显著**，禁止"趋势上仍有一定传导""方向正确"等软化措辞。
4. **相关系数与样本量是结论的组成部分**：没有 r 与 n 的"已验证"不得出现；事件窗结论改为给前后窗数值 + 对照组差异 + 计数单位。
5. **汇总句必须计数**：`共 L 环：已验证 X、不显著 Y、未验证环节 Z（X+Y+Z=L）`。数字对不上即硬失败。

**措辞对照**：

| ❌ 禁止 | ✅ 改为 |
|---|---|
| 政策推动了行业增长 | 政策强度序列与行业变量在 k=X 期错位下正相关（r=…，n=…） |
| 传导已经发生 | 该环通过预设阈值（r=…，n=…，窗口 …）；机制解释仍属假设 |
| 该区域明显受益 | 适用组前后差异 <…>，对照组差异 <…>（n=…，无因果解释） |
| 预计明年见效 | （删除——预测性表述）历史时滞分布见滞后表 |

## 阶段 6：交付结构与口径溯源

1. **结论卡**：政策名 + 环节数 + 三档计数 + 口径日 + 数据截至。
2. **检验参数声明**（结果之前）：路线（事件窗/强度序列）、频度与聚合口径、门槛、K、阈值、method、共执行多少次检验。
3. **逐环主表**：

```
| # | 政策锚（item_id · as_of） | 变量（code · 面板） | 频度/对齐 | 窗口 | k* | r | n | 对照组 | 判定 |
|---|---|---|---|---|---|---|---|---|---|
```

4. **完整时滞表**（强度序列路线）：每环 k → r，缺测写"无数据"。
5. **窗口敏感性表**：全样本 + 近 N 期两窗并列，不一致写"结论依赖窗口"。
6. **未验证环节明细**：按固定格式给原因与恢复路径。
7. **多重检验自曝**。

**口径溯源表**（每次输出必附）：

| 项 | 来源（工具名） | 数据期数 |
|---|---|---|
| 政策锚点与证据 | `mcp__fd-info__get_item` | <published_at> |
| 来源健康度 | `mcp__fd-info__stream_health` | 调用日 <YYYY-MM-DD> |
| 年鉴序列 | `mcp__fd-find-data-business-mcp__yearbook_read` | <起止>，<区域数> 个 |
| 城市面板序列 | `mcp__fd-find-data-business-mcp__city_read` | <起止>，<城市数> 个 |
| 公司面板序列 | `mcp__fd-find-data-business-mcp__gta_read` | <起止>，<公司数> 家 |
| 相关系数与样本量 | `mcp__fd-quant__compute_information_coefficient` | 各环 n=<…> |
| 样本充足性 | `mcp__fd-quant__check_observation_sufficiency` | <调用日> |
| 数据截至 | `mcp__fd-find-data-business-mcp__registry_coverage` | <返回期>（不可用时注明"未经在线核实"） |

## 防编造硬约束（红线）

- ❌ **相关系数、样本量、窗口、期别、前后窗数值全部必须来自工具返回**；取不到就写"未取得"，**禁止编造统计量，不得凭记忆写 r 或 n**。
- ❌ **不得编造 p 值**；计算面不输出 p 值，本稿也不写。
- ❌ **结论必须三档**（已验证 / 不显著 / 未验证环节）；**每条结论必须带相关系数与样本量**（事件窗带前后窗数值与计数单位）。
- ❌ **「未验证环节」不得写成"基本成立""大概率传导"**；不得被叙事吞并、不得跨环替代依据。
- ❌ **不得用因果动词**（导致、推动、引起、决定）描述统计结果。
- ❌ **不得插值、前向填充、向高频展开**来增加样本量；年鉴缺年如实缺。
- ❌ **政策锚点必须有 item_id 与逐字证据**；正文未核实的政策不检验。
- ❌ **判定阈值必须在检验前声明**，不得看结果后调整。
- ❌ **健康度异常必须声明"信息可能不完整"**。

## 降级路径（数据源未连接或调用失败时，强制执行）

| 情形 | 处理 |
|---|---|
| `fd-info` 未连接 | 政策锚点不可得 → 全部环节 `未验证环节（政策锚点未取得）`；不得凭记忆写政策日期 |
| 年鉴/城市/公司面板工具未连接 | 对应环 `未验证环节（序列未取得：<工具名>）`；**不得用其他来源或记忆补序列** |
| 通道 Q 不可用 | 明示"未连接计算面，相关与事件窗无法计算"；只交对齐后的序列与参数声明，全部环记 `未验证环节（计算面不可用）`，**不得手算冒充工具结果** |
| 样本不足 | `未验证环节（样本不足：X < Y）`；不缩窗、不降门槛 |
| 频度无法不造数据地对齐 | `未验证环节（频度不可对齐）` |
| 无对照组 | 事件窗结论必须声明"无对照，前后差异可能含共同趋势"，判定上限为"不显著（无对照）"或并列声明后降档 |
| 政策已撤回 | 不检验，登记"政策已撤回" |

**降级时不产出结论，只产出缺口。** 无工具返回却在表里写出相关系数或样本量，属硬违规。

## 交接

- 输入映射来自 `policy-mapping`（含未验证清单，整表随行）。
- 本技能只交三档判定与统计量，**不交方向结论、不出候选**。
- 需要持续跟踪新政策与已验证链路 → `policy-watch`。
