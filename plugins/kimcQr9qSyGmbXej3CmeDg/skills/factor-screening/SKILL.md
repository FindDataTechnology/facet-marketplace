# 柏讯因子选股 · 选股应用

你的职责：**把因子暴露与分层结论，变成一份可执行的候选名单或目标权重**，并且让每一条筛选条件、每一个权重都能被人复查。

三条边界，先说清楚：

- **打分不是预测**。多因子打分是把若干历史因子值按权重压成一个排序分，它**不代表**未来收益排序，也**不是**涨跌预测。输出里不得出现"预期收益""预计上涨""目标价"这类表述。
- **不做权重最优化**。权重由用户给定或按明示规则（如等权）确定，**不做**黑箱优化、不做均值方差求解。理由是：没有样本外验证体系时的"最优权重"就是样本内过拟合。
- **不做因子择时**。不判断"哪个因子当下有效"，不按近期 IC 调权重（除非用户明确给了该规则并接受这是样本内选择）。

---

## 阶段 0：入口条件（不满足就不产出名单）

| 前置项 | 要求 | 不满足时 |
|---|---|---|
| 因子值 | 每个入选项的每个入模因子都有值，或已按阶段 4 的规则处理 | 不得进入打分 |
| 因子方向 | 每个因子标注"越大越好 / 越小越好"（来自 `factor-library` 的分子分母） | 未标方向不得入模 |
| 暴露与样本 | 该因子在当期横截面的可用标的数 ≥ 8 | 该因子本期退出打分，并写进输出 |
| universe | 明确列出代码清单与时点口径（当期可得 / 当前清单） | 不得开始 |
| 权重来源 | 用户给定，或选中"等权"规则 | 不得自行发明权重 |

**方向必须先对齐**：负债率、估值倍数是"越小越好"，ROE、毛利率是"越大越好"。混合方向直接相加等于把信号抵消，是硬错误。做法：对"越小越好"的因子，先取负号或取名次的补（在 `mcp__fd-quant__rank_factor_scores` 的名次基础上做 `N+1−rank`），并在输出里写明每个因子用的是哪种方向对齐方式。

---

## 阶段 1：两种选股路径（先选一种，再动手）

| 路径 | 做法 | 适用 | 输出的可解释性 |
|---|---|---|---|
| **A. 条件筛选**（先推荐） | 逐条设定阈值条件，全部满足才入选（交集） | 用户有明确偏好（"ROE 大于 X、负债率低于 Y"） | 每条条件都能单独指着说"因为它被排除" |
| **B. 多因子打分** | 各因子对齐后加权求和得总分，按总分排序取前 N | 用户要"综合排序" | 权重必须显式，且要能说出每个因子贡献多少分 |

两条路径可以串联：先用条件筛选缩池，再在池内打分排序。串联时**两段都要各自交代**，不得只讲后一段。

---

## 阶段 2：路径 A —— 条件筛选（逐条可解释）

**条件表的强制形态**（少一列就不算交付）：

| # | 条件 | 因子定义（`factor-library` 条目） | 阈值 | 阈值的依据 | 方向 | 本期排除数 |
|---|---|---|---|---|---|---|
| 1 | 例如「ROE ≥ 阈值」 | 盈利 / ROE（归母净利 ÷ 平均归母净资产） | 由用户给定或按截面分位给定 | 用户指定 / 截面 P60 / 固定值 | 越大越好 | N 只 |

**阈值来源只有三类，必须写明是哪一类**：

1. **用户指定**（原话数字，不得改写）；
2. **截面分位**（如"当期该因子的 P60"；必须写出当期该分位的实际取值与样本数）；
3. **固定历史口径**（如"≥ 0"这类有明确含义的边界）。

**不得**为了让结果好看而调整阈值后不声明。改了阈值就是改了条件，必须重新出表并写明"本轮阈值调整过，原阈值 X，现阈值 Y，原因是 Z"。

**多条条件的排除必须可归因**：最终落选名单要能说出"它是因为第几条被排除的"（若同时触发多条，列出全部）。做不到这一点说明条件没有被逐条执行。

---

## 阶段 3：路径 B —— 多因子打分（权重显式或规则显式）

### 3.1 权重来源（二选一，写在输出最前面）

| 规则 | 内容 | 何时用 |
|---|---|---|
| **等权**（默认） | 每个入模因子权重 = 1 / 因子数 | 用户没有偏好；样本宽度不足以支撑权重差异化 |
| **显式权重** | 用户给定的一组数，归一化到和为 1 后使用；原始值与归一化值都列出 | 用户明确表达偏好（如"盈利占一半"） |

**禁止**：按近期 IC 或分组收益反推权重（那是样本内拟合）、任何形式的自动寻优、任何"模型学出来的权重"。本技能不提供这些，用户要求时如实说明。

### 3.2 打分的算式（必须写出来）

```
总分_i = Σ_k  w_k × z_{k,i}
w_k     = 归一化后的因子 k 权重（等权时 = 1/K）
z_{k,i} = 因子 k 在标的 i 上的方向对齐后处理值（秩名次标准化 或 稳健 Z，按 factor-exposure 阶段 3 的处理方式）
```

`z` 的处理方式必须继承 `factor-exposure` 本次实际用过的那一种（秩变换 / 分位截断 / 稳健 Z），**不得**在打分环节悄悄换一种。

### 3.3 贡献必须可拆

输出里要有一张**单项贡献表**：每个入选标的 × 每个因子 = 该因子贡献的分值，以及总分。这样"它为什么排第一"才能答得出来。

```
标的 | 因子1贡献 | 因子2贡献 | … | 总分 | 排名
```

**不得**只给总分不给分解。只给总分的打分是不可审计的。

### 3.4 取前 N

N 由用户给定（默认 10，但**受 universe 规模约束**）。当前通道 B 只有 12 只 A 股，`N` 超过可用标的数时如实说明"universe 只有 12 只，N 已截到 12"，不得凭空补标的。

---

## 阶段 4：缺失因子处理规则（必须选一条并声明）

**两种规则，选一种，全程一致，输出中可见**：

| 规则 | 做法 | 后果 | 何时用 |
|---|---|---|---|
| **规则 1：剔除该因子并重算权重** | 某因子在某期缺失面过大（可用标的 < 8）时，该因子整体退出本期打分，剩余因子按规则重新归一化（等权时 = 1/剩余因子数） | 留住了标的，但本期的因子构成与上期不同，**跨期不可直接比总分** | 默认。universe 较宽、个别因子偶尔缺失时 |
| **规则 2：剔除该标的** | 只要某标的缺任一入模因子，该标的整只退出本期排序 | 因子构成稳定、可比；但会显著缩小 universe，小样本下可能清空名单 | 因子构成必须逐期一致时（如做多期对比） |

**无论选哪条，都必须**：

1. 在输出首段写明"本期缺失处理规则 = 规则 1 / 规则 2"；
2. 列出本期因缺失被处理的因子或标的（名字 + 缺的科目/期别）；
3. **不得**用 0、中位数、行业均值、上期值或任何插值填充缺失因子值——填充会让回测看起来完整，实际建立在编造上；
4. 规则 1 下若剩余因子数 < 2，本期打分**不成立**，只出条件筛选结果或不产出名单。

**样本下降本身是信息**：如果规则 2 把 universe 砍到只剩 3 只，这就是"该因子组在当前数据面可用性有限"的真实结论，照实写，不得放宽规则来保住名单。

---

## 阶段 5：终产物（可执行出口，不是文字名单）

终产物**必须是**下面两种之一，且能直接进入权重模式：

### 5.1 形态一：候选 universe

```json
{
  "kind": "universe",
  "as_of": "YYYY-MM-DD",
  "symbols": ["600519", "000333"],
  "rationale": "多因子打分前 N / 条件筛选结果",
  "rule": "等权 / 显式权重 <列出>",
  "missing_policy": "drop_factor_reweight / drop_name"
}
```

校验：先用 `mcp__fd-paper-trading__search_instruments` 逐个确认标的在交易服务可见，再用 `mcp__fd-paper-trading__get_bars` 确认所需窗口有真实 bar。**不可见的标的从名单剔除并说明**——不要等回测时才被数据覆盖门禁拒绝。

### 5.2 形态二：目标权重（推荐，一步到位）

```json
{
  "kind": "weight",
  "universe": ["600519", "000333"],
  "rebalance": { "every_n_bars": 20 },
  "weights_series": {
    "YYYY-MM-DD": { "600519": 0.10, "000333": 0.10 }
  }
}
```

权重语义（不可自行发挥）：

- **非负、和 ≤ 1**，余量自动是现金；引擎**拒绝而不归一化**——和超过 1 的权重会被原样拒绝并点名日期与权重和。
- 权重是**目标仓位占比**，不是金额、不是股数。
- **不做空、不加杠杆**：负权重会被契约拒绝。
- 每个调仓日都要给一期权重；只给一期会导致后续无仓可调。

**权重怎么定**（同样只能显式）：

| 方式 | 说明 |
|---|---|
| **等权** | `w = 1/N`（或 `(1−现金余量)/N`） |
| **打分权重** | 按总分占比分配；此时必须说明"用打分当权重是规则，不是最优解" |
| **用户给定** | 原样使用，归一化后列出 |

**不得**在权重环节引入"风险平价""均值方差最优""Black-Litterman"等优化——本技能不做权重最优化。

### 5.3 出口前自检

1. 每个 symbol 都通过了 `search_instruments` 与 `get_bars`；
2. 权重非负、和 ≤ 1、symbol 全在 universe 内；
3. 调仓频率（`every_n_bars`，整数）已给出；
4. 每期权重都有日期键；
5. 缺失处理规则、权重来源、每个因子的方向对齐方式，三样都写在输出里。

之后交给 `factor-backtest-protocol` 做点内回测，或直接调 `mcp__fd-paper-trading__create_strategy` 建 spec。

## 阶段 6：输出模板（照此交付）

```
【口径】
as_of：<日期> ｜ universe：<N 只> ｜ 路径：条件筛选 / 多因子打分 / 串联
权重来源：等权 / 显式权重（列出原始与归一化值）
缺失处理规则：规则 1（剔除因子重算）/ 规则 2（剔除标的）
极端值处理：秩变换 / 分位截断(q_low,q_high) / 稳健Z(k)

【筛选条件】（路径 A）
<五列表格>

【打分构成】（路径 B）
<权重表 + 单项贡献表>

【结果】
候选名单：<代码 + 名称>
目标权重：<每只的权重，和 = X，余量现金 = 1−X>
落选与原因：<逐条>

【溯源】
来源：<工具名> ｜ 数据期数：<起止报告期 / 价格截至日>
```

最后一行**必须**有「来源」与「数据期数」两个字段，缺一不可。

## 防编造硬约束

- 入选标的的每一个因子值、每一个分值、每一个权重**必须来自**工具返回或本稿声明的算式；**禁止编造**因子值与排名。
- **不得**凭记忆列股票代码或公司名；代码**只能来自** `mcp__fd-cn-report__get_company` 或用户给定清单。
- **不得**把打分表述为"预期收益""上涨概率""预测收益"；打分只是当期截面内的相对排序。
- **不得**因结果不理想而回头改阈值、改权重、改缺失规则而不声明；任何一次调整都要留下"改前 → 改后 + 原因"。
- **不得**用估计值填充缺失因子；缺失就是缺失，按阶段 4 的规则处理并写出。
- 交易服务为 **paper-only 模拟盘**：不存在真实下单、真实资金、券商接口；本技能只产出权重与 spec，不触达任何真实委托通道。

## 降级路径

| 情形 | 处理 |
|---|---|
| 通道 B（价格）未连接 | 全部价格依赖因子退出打分：7 个估值因子 + `debt_to_mktcap` + `dividend_yield`（`debt_service_coverage` 若缺明细同样退出）；剩余因子按规则 1 重算权重；若剩余 < 2 个因子，只出条件筛选（非价格条件），并明示"无价格通道，估值与市值为分母的维度缺失" |
| 通道 A 未连接 | 因子值不可得，不产出名单；只交付筛选计划与所需科目清单，标"未经在线核实" |
| universe 只有 12 只（通道 B 现状） | 打分照做但必须写明"横截面仅 12 只，排名靠后的区分度有限"；`N` 截到可用数；分层结论按 `factor-exposure` 的样本门槛处理 |
| 某标的缺入模因子 | 按声明规则处理（剔除因子重算 或 剔除标的），并在输出列出被处理的标的与缺失科目 |
| 某因子可用标的 < 8 | 该因子本期退出打分并写明；不得为保住该因子而降低门槛 |
| 交易服务不可用 | 仍可交付候选名单与目标权重（JSON），明示"未做标的可见性校验，回测入口不可用" |
| 用户要求"自动优化权重" | 明示不做权重最优化；提供等权或让用户给定权重，并说明为什么不做（样本内过拟合、不可审计） |
| 用户要求"预期收益" | 明示打分不是预测，不产出预期收益；可给历史分层收益作为参照，但须标注"历史统计，非预测" |

## 交接

- 要把权重送进开启断言的回测并验点内纪律 → `factor-backtest-protocol`。
