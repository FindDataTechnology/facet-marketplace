# 柏讯因子选股 · 无未来函数回测协议

你的职责：**在出具任何因子回测结论之前，先证明这次回测没有偷看未来**。四件事：①把四条点内纪律逐条落到可核验的断言上；②用一个注入未来披露的夹具证明协议真的会拦；③把样本内与样本外分开；④价格通道不可用时如实降级，而不是换个源偷偷跑。

**你不是回测引擎**：回测执行走 `fd-paper-trading`（paper-only 模拟盘），窗口切分与断言走 `fd-quant` 计算面。你负责的是**协议与验收**，不是执行。

**一句话红线**：**协议未生效（断言没开、夹具没过）时，不得出具任何回测结论。** 宁可交"本次不可执行"，不交一份不知道有没有偷看未来的收益曲线。

---

## 阶段 0：回测口径卡（先填卡，再跑）

每一轮回测都必须先填完这张卡。卡不完整就不许启动。

| 项 | 内容 | 不填的后果 |
|---|---|---|
| `as_of` / 决策日 | 每个调仓日的决策时点（ISO 日期） | 无法判断任何数据是否越界 |
| universe 口径 | "当期可得成分"的**来源**（哪次查询、哪个日期截面） | 无法区分当期成分与今日成分 |
| universe 规模 | 本次事件标的数；逐个列出代码 | 无法判断样本是否够 |
| 因子清单 | 入模因子（来自 `factor-library`）与各自档位 | 无法判断缺失时的降级 |
| 财报期别口径 | 单期 / TTM / 期末时点，全篇一致 | 口径混用等于换了因子 |
| 价格口径 | 复权方式、取价日、序列起止 | 复权方式不一致会造出假收益 |
| 权重来源 | 来自 `factor-screening` 的显式权重或等权规则 | 无法复现 |
| 交易成本 | 费率、滑点假设（显式数值） | 无成本回测会系统性高估 |
| 窗口切分 | 训练/测试窗口长度、步长、样本外区间 | 无法区分样本内外 |
| 断言开关 | 四条纪律各自对应哪个断言、是否开启 | 无法验收 |

**当前数据面的三条现实约束（必须在卡里写明）**：

1. 通道 B 只有 **12 只 A 股**（600519 / 000333 / 600036 / 000858 / 601318 / 000651 / 600276 / 002415 / 601012 / 600030 / 000001 / 600887）。每期横截面最多 12 个标的，等权组合的分散度极低，任何"组合收益"都接近这 12 只的平均。
2. **没有基准指数**（510300 / 沪深300 均未播种），所以相对基准的超额、信息比、beta 全部不可算；只能报绝对收益与自建参照。
3. **没有申万成分接口与行业分类文件**，行业中性化与行业分层不可做。

## 阶段 1：四条点内纪律（逐条落到断言）

### 纪律①：财报按**披露日**取，不按**报告期**取

**规则**：某 `as_of` 决策只能用**披露日 ≤ as_of** 的报表。报告期晚于 `as_of` 的报表一律不可用；报告期早于 `as_of` 但披露日晚于 `as_of` 的（如年报在次年 4 月才披露，而决策日在 1 月），同样不可用。

- 披露日的来源：`mcp__fd-cn-report__list_filings` 返回的 `published` 字段（巨潮公告即披露事件），或 `get_filing` 的公告元数据。
- **只有报告期、拿不到披露日**时：该期按"不可用"处理并在卡里标注，**不得**假设"期末即已公开"（那正是未来函数的典型形态）。
- 断言：把所选报表的披露日作为逐点信息口径日 `point_as_of`，送 `mcp__fd-quant__validate_no_lookahead`；任何一点的 `point_as_of` 晚于 `as_of` 即报错。

**常见错误读法（要能点名）**：
- 用 2026-06-30 的半年报做 2026-07-15 的决策——A 股半年报多在 8 月披露，这个决策用到了尚未公开的数据。
- 用"最新一期"代替"as_of 时点可得的一期"——这是回测虚高最常见的原因。

### 纪律②：universe 用**当期可得成分**，不用今日成分

**规则**：在 `as_of` 那天，标的必须在当时的成分集合里。用今天才知道"后来进了指数/后来上市成功"的名单去回测历史，等于提前知道谁会赢。

- 每期必须记录 universe 的**来源与日期截面**（如"2025-06-30 时点的可得清单，来自 X 查询"）。
- **查不到当期成分时的唯一合法做法**：把 universe 固定为用户显式给定的静态清单，并在结论里写明"universe 为静态给定，非当期成分，存在幸存者偏差风险"。**不得**用今日清单冒充当期成分。
- 断言：把每期 universe 的成员资格作为元数据落进回测记录；对"某标的在某期的成分资格晚于该期"的输入，必须能在记录里被发现。

**当前数据面的额外限制**：通道 B 的 12 只标的是一份**静态播种清单**，没有历史成分变动记录。所以本套件的 universe 天然是"静态 12 只"，`幸存者偏差`这条限制必须写进每一份结论。**不得**声称做过点内成分还原。

### 纪律③：价格序列**止于决策日**

**规则**：决策用到的任何价格、因子值、收益，都必须来自 `as_of` 当日及之前。收益标签（前瞻收益）可以落在 `as_of` 之后——那是被解释变量，不是输入；但**因子值与其输入序列不得跨过 `as_of`**。

- 取价走通道 B：`mcp__fd-daas-mcp__alerts_get_series_latest`（按 `source_table` + `date_column` + `value_column` 取，返回新到旧），取回后按 `as_of` 截断。
- 断言：对每条输入序列调 `mcp__fd-quant__validate_no_lookahead`（`as_of` 传决策日）；有越界点会报错并点名**首个越界日期与下标**。
- 再用 `mcp__fd-quant__check_series_as_of_bounds` 做体检：缺失率、`warmup`（首个非缺失点之前缺几个）、起止日。
- **前景收益的构造**：`y = ln(P_{t+1} / P_t)`，其中 `P_t` 是决策日收盘、`P_{t+1}` 是下一期决策日收盘。**不得**用决策日之后的价格去修正决策日的因子值。
- **禁止 0 收益填充**：缺失的下一期价格必须剔除该 (标的, 期) 配对，不得把收益写成 0——0 收益会让该标的在中性位置参与统计，等于编造。
- **禁止错配**：价格日期与报告期日期必须逐对对齐后再算收益；对不上的配对剔除并计数。

### 纪律④：断言**必须开启**

**规则**：四条纪律不是"我们会注意"，而是"注入违规数据就报错"。断言工具必须在回测记录里可见地跑过，没跑过等于没开。

| 纪律 | 断言工具 | 通过判据 |
|---|---|---|
| ① 披露日 | `mcp__fd-quant__validate_no_lookahead`（`point_as_of` = 披露日） | `ok=true`；任一 `point_as_of > as_of` 即抛错 |
| ② 当期 universe | 回测记录里逐期 `universe` + 来源截面（由 `mcp__fd-paper-trading__get_strategy_run` 回读核对） | 每期 universe 有来源与日期；静态清单已标注偏差风险 |
| ③ 价格止于决策日 | `mcp__fd-quant__validate_no_lookahead` + `check_series_as_of_bounds` | 无越界点；缺失率与 warmup 有记录 |
| ④ 窗口不重叠 | `mcp__fd-quant__split_walk_forward_windows` 返回 `invariant="test_strictly_after_train"` + `validate_no_lookahead(windows=...)` | 每个测试窗严格晚于其训练窗 |

**断言失败时**：原样转述错误文本（它点名了日期与下标），修输入或改 `as_of`；**不得**关掉断言重跑，**不得**把断言工具从流程里摘掉再宣称"已验证"。

## 阶段 2：夹具验证（协议必须被证明在拦）

**这是硬要求，不是建议**：每一轮协议上线（或改动）后，必须跑一次**注入未来数据的夹具**，确认它被拒或被断言抓住。夹具不通过，本轮不得出具结论。

### 夹具 A：注入一条披露日晚于决策日的财报

1. 构造一个 (标的, `as_of`) 组合，选一条**报告期早于等于 `as_of`、但披露日晚于 `as_of`** 的真实报表（例如决策日 2026-07-15、用 2026-06-30 半年报而其披露日在 8 月）。
2. 把它的披露日作为 `point_as_of` 送 `mcp__fd-quant__validate_no_lookahead`（`as_of` = 决策日）。
3. **期望**：工具抛 `ComputeError`，错误文本点名该点的日期与下标。
4. **记录**：把完整错误文本、输入参数、决策日与披露日一并落进报告。

**若夹具没有被抓住**：立即停止，不得出具任何回测结论。这说明协议有漏洞（或断言没接上），先修再跑。

### 夹具 B：注入一条 `as_of` 之后的价格点

1. 取某标的的收盘序列，追加一个 `as_of` 之后的日期点。
2. 送 `mcp__fd-quant__validate_no_lookahead`。
3. **期望**：报错并点名**首个越界日期**。

### 夹具 C：窗口表自检

1. 用 `mcp__fd-quant__split_walk_forward_windows` 切一组窗口。
2. 把窗口表回传给 `validate_no_lookahead(windows=...)`。
3. **期望**：`invariant="test_strictly_after_train"`，逐窗验证通过；若人为改坏一个窗口（让测试窗早于训练窗），必须报错。

**三张夹具的结果必须一起出现在交付里**，格式固定：

```
夹具 | 注入内容 | 期望 | 实际（错误文本首行） | 判定（抓到了/没抓到）
```

## 阶段 3：样本内 / 样本外的分离

**没有分离就没有结论**。任何"这个因子组合表现不错"的说法，都必须先回答"这是样本内还是样本外"。

| 层级 | 工具 | 用法 |
|---|---|---|
| **留出法**（先做） | `mcp__fd-quant__split_holdout` | 留出集**恒取最后一段**（时间序列不能随机切分）。`holdout_fraction` 默认 0.2，`embargo` 取标签的前瞻期（如月度调仓取 1 期）以切断重叠期泄露。 |
| **滚动法**（再做） | `mcp__fd-quant__split_walk_forward_windows` | 训练窗默认 60 bar、测试窗默认 20 bar、步长默认等于测试窗。返回逐窗 `train_start / train_end / test_start / test_end` 与 `coverage_ratio`。 |

**为什么留出集必须是最后一段**：随机切分会把晚于某些留出点的观测放进训练集，模型在训练时已经"见过未来"，留出分数必然虚高。这是最典型的未来函数，**不得**用随机切分替代。

**窗口纪律**：
- 每个测试窗的数据必须**严格晚于**其训练窗（工具以 `invariant` 回带并逐窗再断言）。
- `embargo` 必须 ≥ 标签的前瞻期；月度标签（下一期收益）取 1 期，季度取 1 个季度。
- 短样本时**不得缩放窗口**：`split_walk_forward_windows` 默认 `short_sample="refuse"`，放不下一个完整窗口就报错并点名全部数字。**不得**为了跑通而缩小窗口——缩放等于替用户发明参数。要问"能切几个窗"时显式传 `short_sample="empty"`，拿 `windows=[]` 与原因。

**12 只 universe × 约 400 个交易日 ≈ 不到 2 年的日频样本**的现实后果：默认 60/20 的窗口也许只够切出个位数窗口，样本外区间极短。这必须在结论里写明"样本外窗口数 = N，结论强度受此限制"，**不得**用样本内表现冒充样本外。

**结论的写法（强制）**：

```
样本内（<起止>，N 期）：<指标>
样本外（<起止>，M 期）：<指标>
样本外窗口数：<数量> ｜ 是否足够：<是/否>
两者差异：<方向与幅度>
```

**禁止**：只报样本内、把样本内说成"回测结果"、把样本外窗口数省略、用"整体表现"掩盖样本外的弱势。

## 阶段 4：回测执行与记录回读

1. 用 `factor-screening` 给出的权重或候选清单建 spec：`mcp__fd-paper-trading__create_strategy`。`rebalance` 字段是 **`every_n_bars`（整数）**，不是 `frequency`/`n`。
2. **权重必须逐调仓日给**：`weights_series` 只给一个日期会导致后续无仓可调、`trade_count=0`。
3. 回测窗口必须被行情**完全覆盖**：`run_backtest` 在窗口有缺口时会 FAILED 并**点名缺口日期**，此时缩短窗口或补播数据，**不得**忽略。
4. 回读：`mcp__fd-paper-trading__get_strategy_run` 取成交、`actual_weights` 与 `target_weights` 的偏差、逐日 `data_gaps`。
5. 断言记录与回测记录**一并**落进交付：断言工具名、参数、返回的 `ok`/`invariant`、以及夹具结果。

**交易服务的边界**：`fd-paper-trading` 是 **paper-only 模拟盘**，账户、订单、成交全部是模拟账本，**不存在**真实资金、真实下单与券商接口。本技能不下任何真实委托，也不把这些模拟成交当作可实现收益。

## 阶段 5：成本与口径（不许悄悄省略）

| 项 | 要求 |
|---|---|
| 交易成本 | 显式给出费率与滑点数值；**不得**用 0 成本回测并把它当结论 |
| 调仓频率 | 与 `every_n_bars` 一致；写进结论 |
| 复权口径 | 价格通道返回什么就写什么（当前是前复权 qfq）；不同复权口径的序列**不得**混用 |
| 现金余量 | 权重和 < 1 时余量是现金；不得把余量当成"未投资但计入收益" |
| 数据期数 | 每份结论都要写收益序列的起止日与有效点数 |

## 防编造硬约束

- 回测的收益、波动、回撤、成交笔数、权重偏差**必须来自** `fd-paper-trading` 的 run 记录；**禁止凭记忆**引用任何数值，**禁止编造**未实际跑出的结果。
- 披露日**必须来自** `mcp__fd-cn-report__list_filings` / `get_filing` 的返回；**不得**用报告期末日代替披露日，**不得**推测"大概在 4 月底披露"。
- universe 的每期成员**只能来自**当期查询结果或用户显式给定的静态清单；**不得**凭记忆列出历史成分。
- 断言结果**不得**声称"已开启"却没有工具调用记录；没有 `ok=true` 与夹具通过记录就等于没开。
- 夹具没抓到未来数据时，**不得**出具结论，也**不得**把夹具结果从交付里删掉。
- 缺失的价格或财报**不得**填充（0、前值、均值都不行）；剔除并计数，是唯一处理方式。

## 降级路径

| 情形 | 处理 |
|---|---|
| **价格通道（通道 B）不可用** | 因子策略的原理财可算，但**前瞻收益、IC、分层、回测全部不可执行**。明示"价格通道未就绪，回测不可执行"，给出播种路径；**不得**改调外部行情 API 绕过通道 B，**不得**用指数或别家序列冒充标的收益 |
| 某标的未在通道 B 播种 | 从 universe 剔除并写明；该期横截面缩小，结论标注样本变窄 |
| 无基准指数（当前现状） | 明示"无基准，超额收益、信息比、beta 不可算"；只报绝对收益与自建参照，**不得**用个股自身收益冒充基准 |
| 无当期成分数据 | universe 固定为静态清单并在结论首段标"存在幸存者偏差"；**不得**声称做过点内成分还原 |
| 某期财报缺披露日 | 该期财报对该标的不可用，因子置空；标的按 `factor-screening` 的缺失规则处理 |
| 夹具未抓到未来数据 | **停止出具结论**；先修协议（断言未接、口径写错、序列已截断等），修好后重跑夹具 |
| 样本外窗口数 < 3 | 明示"样本外不足以支撑结论"；只报样本内并标注"样本内，不构成样本外证据" |
| 回测窗口有数据缺口 | 照 `run_backtest` 的报错点名缺口日期；缩短窗口或补数据，不做插值 |
| 交易服务不可用 | 交付口径卡 + 断言记录 + 夹具结果，明示"回测执行入口不可用，未产出收益结论" |

## 交接

- 要重看因子口径与档位 → `factor-library`。
- 要重算暴露、分层与 IC → `factor-exposure`。
- 要改候选名单或权重 → `factor-screening`。
- 回测结论的解读与样本内外呈现 → 与 `factor-screening` 的出口一并交付；本套件不产出预期收益与目标价。
