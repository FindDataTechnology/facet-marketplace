# 柏讯 · 组合风险

柏讯组合风险四件套：风险预算（单票与板块上限 + 超限按比例重分配 + 迭代上限显式 + 未收敛如实报告，产出合规 TargetWeights）、回撤与波动体检（最大回撤起止/年化波动/HHI/前 N 占比/行业集中度/有效标的数 + 基准超额与跟踪误差，指标走计算面，体检不预测）、止损纪律（量级起点 -5%/-10%/20 日冷却 + 按标的波动重标 + 三处明示引擎不自动执行 + 触发检查只呈现状态不新增判断）、再平衡方案（逐标的差额/方向/股数 + 佣金印花税滑点分项成本 + 可送权重模式回测 + 不含择时）。与决策复盘套件的分工：复盘看现状（集中度/回撤/偏离），本套件定纪律（预算怎么分、止损怎么设、什么时候该动手），一静一动。与策略工坊的分工：工坊讲通用参数含义，本套件把纪律应用到用户的实际持仓上。paper-only：无真实资金；所有指标是历史与当前状态描述，不构成投资建议。

## 技能

- portfolio-budget — 柏讯组合风险 · 风险预算。当用户要求"资金怎么分到这些标的/行业""单票最多放多少""按上限重新分配一遍"时使用。产出：一份**生成即合规**的 TargetWeights 契约实例（单票上限 + 板块上限 + 迭代重分配，迭代上限显式，未收敛如实报告）+ 约束满足表。只管权重结构，不管"该投多少钱"；现金靠 Σweights < 1 留出，引擎不会替你扣。
- portfolio-drawdown-review — 柏讯组合风险 · 回撤与波动体检。当用户要求"看看这个组合的回撤有多深""波动多大""是不是太集中了""和沪深300比怎么样"时使用。产出：组合级指标（最大回撤含峰谷日、年化波动、HHI、前 N 占比、板块集中度、有效标的数）+ 基准对比（超额与跟踪误差）。指标一律来自 fd-quant 计算面，不手算、不预测，缺失如实标注。
- portfolio-stop-discipline — 柏讯组合风险 · 止损纪律。当用户要求"止损设多少""移动止损怎么定""止损设了会自动执行吗""帮我看看哪些已经跌破线了"时使用。产出：一份用户既定的止损规则（绝对止损 / 移动止损 / 冷却期，含量级起点与按波动重标的方法与依据）+ 触发检查的状态呈现（当前值 vs 阈值 + 冷却剩余）。**本技能必须首先声明：这些是用户的纪律设定，不是引擎保证——引擎不会自动执行止损，权重模式只消费 weights_series，契约的 constraints 只有单票与板块两个上限字段，没有任何止损字段。**
- portfolio-rebalance-plan — 柏讯组合风险 · 再平衡方案。当用户要求"从现在的持仓调到这个目标权重，具体买什么卖什么""每只调多少股""调仓成本大概多少""这套再平衡规则历史上表现如何"时使用。产出：逐标的差额 / 方向 / 整数股数（向下取整，与权重模式引擎同口径）+ 成本预估（佣金 / 印花税 / 滑点分项，参数显式）+ 可送入权重模式回测的权重规则。**方案不含择时建议**；并明确引擎不自动执行止损、只消费 weights_series，cash_floor 只是权重上限校验而非独立持仓约束。

## MCP 连接指引

本插件声明以下 MCP 引用（**不随插件自动连接**——插件本体不携带任何服务器配置或凭据）：

- **fd-paper-trading** — 端点 `https://mcp.finddatatech.cloud/fd-paper-trading/mcp`（需要组：wire-customers）
- **fd-quant** — 端点 `https://mcp.finddatatech.cloud/fd-quant/mcp`（需要组：wire-customers）
- **fd-daas-mcp** — 端点 `https://mcp.finddatatech.cloud/fd-daas-mcp/mcp`（需要组：wire-customers）
- **wire-build-mcp** — 端点 `https://mcp.finddatatech.cloud/wire-build-mcp/mcp`（需要组：wire-customers）

连接方式：支持 MCP OAuth 的客户端可直接对该端点授权；否则用谦面 CLI 铸取调用键后写入本机配置：

```
npx @finddatatechnology/facet connect
npx @finddatatechnology/facet install <packRef> --target workbuddy --write-mcp
```
