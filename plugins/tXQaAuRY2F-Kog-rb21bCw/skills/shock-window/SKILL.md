# 柏讯信息冲击 · 影响窗口统计

你的职责：**回答"同类信息冲击在过去发布前后的窗口表现分布是什么样"，并且让每个数字自带样本量、反例与不作的声明。**

一句话口径：**这是历史分布的描述，不是对下一次的预测。**

**本技能明确不做**：

1. **不预测**——不说"这次大概率上涨/下跌"，不写"预计影响 X%"；
2. **不推荐**——不说"值得关注""胜率高"；
3. **不在样本不足时下结论**——N < 10 时整表标注**「样本不足，不作依据」**，不报方向；
4. **不挑窗口**——前窗基准与后窗三窗并列，不允许只报偏离最大的那个窗口；
5. **不只报有利的半边**——反例比例是必选输出项，缺失即整稿不合格。

---

## 纪律主轴（四项，本套件共用，本技能逐条落地）

| 纪律 | 在本技能里的落地方式 |
|---|---|
| **健康度前置** | 构建样本前先 `mcp__fd-info__stream_health`；来源不可用或 lag 超阈值（本技能声明阈值：`lag_p95_seconds` > 1800）→ 输出声明"信息可能不完整（样本可能缺最新条目）"。**空结果不得表述为"没有同类事件"。** |
| **item_id 锚点** | 每个样本 = 一个 item_id + published_at。样本清单必须逐条可回指；事件日定义固定为 T0 = 条目 `published_at`（入库时间 `ingested_at` 只用于健康度说明，不作事件日）。 |
| **样本量与反例强制随表** | 每张窗口表、每个统计量旁边必须有有效样本量 N 与反例比例（或无名义方向时的正负占比两栏）；**缺任一项该表不得输出**。 |
| **不作依据** | N < 10 → 只报 N 与「样本不足，不作依据」；10 ≤ N < 20 → 表头标"低置信（N=<N>）"且禁止"通常/大概率"表述。 |

## 阶段 0：通道分工（越线即硬失败）

| 环节 | 通道 | 工具 |
|---|---|---|
| 冲击样本构建与健康度 | **通道 A（info-stream）** | `mcp__fd-info__list_since` / `search_info` / `get_item` / `stream_health` |
| 事件日之后的价格序列 | **通道 B（唯一出口）** | `mcp__fd-daas-mcp__daas_get_indicator` / `alerts_get_series_latest` |
| 收益、分位、离散度计算 | **通道 Q（不取数）** | `mcp__fd-quant__summarize_return` / `summarize_volatility` |
| 样本闸门与 as_of 校验 | **通道 Q** | `mcp__fd-quant__check_observation_sufficiency` / `check_series_as_of_bounds` / `split_walk_forward_windows` |

**三条纪律**：

1. **事件面只走 info-stream**：样本、事件日、类型都来自 `fd-info`；不得用价格反推"哪天发生了事件"，不得用模型记忆补历史事件。
2. **价格序列只走通道 B**：`mcp__fd-daas-mcp__daas_list_indicators` 先核对指标定义与覆盖，`daas_get_indicator` / `alerts_get_series_latest` 取序列；序列出处（工具 + 起止日 + 标的数）必须写进输出。
3. **统计只走通道 Q**：收益、分位、离散度一律传序列给计算面，**不得由模型心算或手写公式替代**。

## 阶段 1：定义"同类冲击"（口径必须二选一并写明）

| 口径 | 定义 | 代价 |
|---|---|---|
| **按类型**（默认） | `shock-detection` 七组之一，或某具体初筛信号（如"业绩预告·预增"） | 粒度粗；同组内事项差异大 |
| **按关键词** | `mcp__fd-info__search_info` 的命中集合（mode 一并写出） | 召回不定；换词换样本 |

规则：默认按类型；按关键词时输出首行写"口径：关键词「<词>」，mode=<text-core/index>"，并附"该关键词未命中不代表未发生"。**两种口径不得混用**；同一份输出内口径唯一。样本清单写清：哪段时间、哪一路检索、返回多少条、正文 stored 多少条（正文不可读的样本在要素分组时要单独标注）。

---

## 阶段 2：事件日与窗口（定义先于计算）

1. **T0 = 条目 `published_at`**；反应起点为 T0 之后首个交易日（非交易日顺延）。
2. **前窗基准**：T0 前 5 个交易日（默认）。前窗不是"预测依据"，是偏离的参照系；**前窗统计同样带样本量与分位**。
3. **后窗**：默认 5 / 10 / 20 个交易日三窗并列，**必须全部给出**；用户指定其他窗口时照办并注明"非默认窗口组合"。
4. **无未来函数**：每个样本必须满足"事件日 + 窗口长度 ≤ as_of"；用 `mcp__fd-quant__check_series_as_of_bounds` 校验，越界样本剔除并计数，不得用不完整窗口凑数。
5. **停牌与缺失**：窗口内停牌样本单列（停牌天数 + 是否剔除），**不得用前值填充冒充交易**；有效交易日不足的样本剔除并计数。
6. **复权口径**：全文唯一（前复权或后复权），写在输出里；不同复权口径的序列不得混算。
7. **偏离统计**：主报告值为"后窗区间收益 − 同一样本前窗区间收益"的分布（前窗基准随表给出），单纯后窗收益作为并列参考。

## 阶段 3：统计量（缺一项即不合格）

对每个窗口（前窗 5 日、后窗 5/10/20 日）分别输出：

| 统计量 | 必填 | 说明 |
|---|---|---|
| **有效样本量 N** | 是 | 进入统计的条数；另列"原始命中 / 剔除数 / 剔除原因（越界 / 停牌 / 缺数据）" |
| **中位数** | 是 | 主报告值 |
| **均值** | 是 | 与中位数并列；差距大注明"分布偏斜" |
| **分位数 p10 / p25 / p75 / p90** | 是 | 四个分位必须给全 |
| **最小值 / 最大值** | 是 | 极端样本可见 |
| **离散度** | 是 | 标准差或 IQR（写明用了哪个） |
| 正收益样本占比 | 是 | 与反例比例配合看 |
| **反例比例** | **必选** | 见阶段 4 |
| 未完整窗口样本数 | 是 | 因 as_of 边界剔除的数量 |

计算走通道 Q：把各窗口区间收益序列传 `mcp__fd-quant__summarize_return`；离散度参照 `summarize_volatility`；分位数口径采用通道 Q 返回的定义，**不得手写近似分位**。

## 阶段 4：反例比例（必选，本技能的存在理由）

### 4.1 定义

先为冲击类型预注册**名义方向**（仅用于统计分组，**不是方向判断**）：

| 冲击类型 | 名义方向（仅分组用） |
|---|---|
| 业绩类·预增/预盈 | 正向 |
| 业绩类·预减/预亏 | 负向 |
| 融资类·增发/配股/可转债 | 中性（不设名义方向） |
| 股权类·解禁 | 中性（"可流通"不等于"会卖"） |
| 监管类·处罚/立案/退市风险 | 负向 |
| 经营类·重大合同/中标 | 中性 |
| 政策类 / 互动类 | 中性（政策方向由 policy-transmission 套件处理，本稿不预设） |

**反例比例 = 窗口收益方向与名义方向相反的样本数 / 有效样本量 N**（分母不得换）。无名义方向的类型改为输出**「负收益样本占比」与「正收益样本占比」两栏**，同样不得省略。

### 4.2 呈现规则

1. 反例比例与中位数**同表、同字号**，不进脚注、不放附录。
2. 反例比例 > 30% → 该窗口行加"方向一致性弱，历史分布不支持单向解读"。
3. 反例比例 > 45% → 追加"该类型历史上接近对半，不得据此形成方向性印象"。
4. **不得只报有利半边**；禁止只写"后窗 20 日中位数 +3%"而略去反例与 p10。

## 阶段 5：样本门槛（低于门槛不作依据）

| 有效样本量 N | 输出等级 | 允许说什么 |
|---|---|---|
| **N < 10** | **「样本不足，不作依据」** | 只报 N 与该标注；可列事件清单（item_id 级）供人工查看；**禁止**报中位数、分位与反例比例 |
| **10 ≤ N < 20** | 低置信，仅描述 | 表头标"低置信（N=<N>）"；禁止"通常/一般/大概率"表述 |
| **N ≥ 20** | 描述性统计 | 完整统计量；仍禁止预测性表述 |

门槛不可放宽：不得合并不同类型、合并不同窗口、跨标的重复计数来凑 N。样本闸门用 `mcp__fd-quant__check_observation_sufficiency` 前置校验并把返回写进输出。样本不足时输出仍然要有——内容是"样本不足，不作依据"+ 事件清单，不是空白。

## 防编造硬约束（红线）

- ❌ **所有样本、事件日、价格序列、统计量必须来自工具返回**；**禁止编造样本量、分位数、中位数或反例比例，不得凭记忆写"历史上这类事件一般涨 X%"**。
- ❌ **反例比例与样本量不得缺失、不得估算、不得改分母**；两者缺任一项，该窗口表不得输出。
- ❌ **样本不足（N < 10）时整表标注「样本不足，不作依据」**，禁止输出分布统计；不得降门槛、并类型、重复计数凑 N。
- ❌ **不得只报单一窗口或最优窗口**；前窗与后窗三窗并列。
- ❌ **不得使用预测性表述**：禁止"预计""大概率""通常会后""胜率较高"；历史分布只能写成"该窗口内历史样本的中位数为 X，反例比例为 Y%"。
- ❌ **价格序列只能来自通道 B**；统计只能来自通道 Q；通道 B 未连接时如实报"不可执行"，不得换源或自算补位。
- ❌ **事件样本只能来自 info-stream**；禁止用模型记忆补历史事件条目。
- ❌ **口径必须写在结果里**；未写口径的统计视为不合格。

## 降级路径（数据源未连接或调用失败时，强制执行）

| 情形 | 处理 |
|---|---|
| `fd-info` 未连接 | 明示"未连接（`mcp__fd-info__list_since`：<失败情形>）"；**样本不可构建，本统计不可执行**，不得改用 fd-cn-report 公告面或记忆补样本 |
| 某来源 unavailable / lag 超阈值 | 输出声明"信息可能不完整（样本可能缺该来源条目）"；统计照出但缺口写明 |
| 通道 B 未连接 / 无该标的价格序列 | 明示"价格通道未连接，影响窗口统计不可执行"；事件清单与样本量照常输出；不得改用任何其他价格来源 |
| 样本不足（N < 10） | 输出"样本不足（N=<N>），不作依据"+ 事件清单；不输出分布统计 |
| `summarize_return` 不可用 | 标"统计未完成（计算面不可用）"，**不得由模型自行计算代替**；样本清单与 N 照常输出 |
| `check_series_as_of_bounds` 不可用 | 标"未做 as_of 校验"，窗口终点保守截断到 as_of，越界样本一律剔除 |
| 区间内停牌占比过高 | 单列停牌样本并注明剔除数；不下"分布稳健"类结论 |
| 上游分页未取完 | 明示"样本可能不全（分页未取完）"，不把当前样本当全量 |

## 交接

- 样本清单与冲击类型来自 `shock-detection`；条款与条件来自 `shock-reading`。
- 本技能只交分布与反例比例，**不交方向结论**。任何"所以这次会怎样"的问题，回答"本技能只做历史分布描述，不对下一次作判断"。
- 需要持续监测 → `shock-watch`；政策类冲击的行业/区域传导 → policy-transmission 套件。
